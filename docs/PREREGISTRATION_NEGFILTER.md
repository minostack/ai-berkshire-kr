시점이 다르지만, SUE 데이터 자체는 같다. 그러므로 결과가 좋아도 **확증이 아니다.**

## 3. 가설과 검정

### 주가설 (BH-FDR)

**H1 — 필터가 나쁜 것을 골라내는가**: 제외군과 유지군의 **신호 단위 초과수익
평균 차이** < 0

- 신호 i의 초과 e_i = 순수익_i − 같은 날 유니버스 동일가중 순수익
- 통계량 = mean(e | 제외) − mean(e | 유지)
- 신뢰구간: 신호일의 **달력 분기 군집** 부트스트랩(4,000회, seed 20260927) —
  제외군이 드물게 흩어져 있어 날짜 블록보다 분기 군집이 맞다

**H2 — 필터를 단 B의 경제성**: 유지군 B 순수익 − KOSPI200 지수(비용 없음) > 0,
2017-01-01 ~ 2026-08-13

- B H2와 같은 방식(신호일 계열, 이동 블록 20, 4,000회)

### 판정

| H1 | 조건 |
|---|---|
| `FILTER_HELPS` | 구간 전체 < 0, q ≤ 0.05 |
| `FILTER_HURTS` | 구간 전체 > 0 |
| `UNDERPOWERED` | 구간이 0 포함, \|관측\| < MDE |
| `NO_SIGNIFICANT_EDGE` | 구간이 0 포함, \|관측\| ≥ MDE |

H2는 B와 같은 규칙(SIGNIFICANT_EDGE / SIGNIFICANT_NEGATIVE / UNDERPOWERED /
NO_SIGNIFICANT_EDGE). `FILTER_HELPS`가 나와도 "발견"이 아니라 "전향 데이터로 확인할
후보"다.

### 미리 적는 예상

제외군은 B 신호의 **소수**(추정 5~15%)일 것이다. 그러면 H1 구간이 넓고 H2는 B의
H2와 거의 같을 것이다 — 필터가 H2를 바꿀 여지는 제외 비율에 비례한다.
