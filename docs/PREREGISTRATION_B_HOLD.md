## 2. 가설과 검정

### 주가설 — 4개를 한 가족으로 BH-FDR

| ID | 무엇 |
|---|---|
| H1-40 | h=40, B 순수익 − 같은 날 유니버스 동일가중 순수익 > 0 |
| H1-60 | h=60, 같은 비교 |
| H2-40 | h=40, B 순수익 − KOSPI200 지수(비용 없음) > 0 |
| H2-60 | h=60, 같은 비교 |

- 통계: B와 같다 — 신호일 계열 이동 블록 부트스트랩, **블록 길이 = h**, 4,000회,
  seed 20260927, MDE = 2.8 × SE
- 판정 규칙도 B와 같다(SIGNIFICANT_EDGE / SIGNIFICANT_NEGATIVE / UNDERPOWERED /
  NO_SIGNIFICANT_EDGE). 유의가 나와도 "작성일 이후 데이터로 확인할 후보"

### 미리 적는 예상

h가 길수록 SE도 커진다(겹침·블록 길이). **H2가 h=20에서 0이었으므로, h=60에서 유의해지려면
비용 전 지수 대비 초과가 보유기간에 비례 이상으로 커져야 한다.** `UNDERPOWERED`가 나올 가능성이
높다고 본다.

### 보조 (서술용)

| ID | 내용 |
|---|---|
| S1 | 같은 기간(~2026-06-12) h=20 — B 원래 결과와 기간 차이 효과를 분리하기 위한 기준 |
| S2 | 재신호 억제 = h(40·60)로 바꾼 변형의 H1·H2 — 겹침을 없앤 경우 |
| S3 | 비용 전(gross) 지수 대비 h=20·40·60 — 비용 희석 효과를 직접 보이기 위함 |
| S4 | 2010-2017 / 2018-2026, 코스피200 / 코스닥150 소속 — h=60, 부호만 |
| S5 | 연도별 h=60 평균 초과 |

### 하지 않을 것

- h를 40·60 외로 늘리거나(80, 120 등) 중간값(30, 50)을 추가하지 않는다
- 게이트 임계값을 바꾸지 않는다
- S2(억제=h)가 더 좋아도 주 결과로 올리지 않는다

## 3. 무엇이 나오면 무엇을 하나

| 결과 | 다음 |
|---|---|
| H2-40 또는 H2-60 유의 | B 스캐너의 권장 보유를 그 h로 **표시**하고 전향 기록으로 확인 |
| H1만 유의, H2 `UNDERPOWERED` | B는 "선정 정보는 있으나 지수를 이긴다는 증거는 없다"로 확정. 전향 기록만 |
