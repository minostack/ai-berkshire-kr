## 1. 신호 정의 — 스캐너 코드를 그대로 쓴다

백테스트는 `tools/ab_candidate_scanner.py`의 상수와 게이트 함수(`b_gate`)를
**import해서** 쓴다. 지표 계산은 속도를 위해 벡터화하되, 스캐너의 `b_metrics`와
같은 값이 나오는지 단위 테스트로 고정한다.

| 항목 | 값 |
|---|---|
| RVOL | 최근 5거래일 평균 거래량 ÷ 그 전 50거래일 평균 거래량 (종목 자신의 봉 기준) |
| 52주 근접 | 종가 ÷ 최근 252봉 고가 최대 |
| 게이트 | 252봉 중 240봉 이상 · RVOL ≥ 1.5 · 근접 ≥ 0.90 · 20일 평균 거래대금 ≥ 10억 |
| 신호일 D | 그 종목의 봉이 D에 있어야 한다 |
| 재신호 억제 | 같은 종목은 **직전에 센 신호로부터 20거래일 안의 재통과를 세지 않는다** (RVOL 5일 창 때문에 같은 사건이 며칠 연속 통과하는 것을 한 번으로 센다) |

| 항목 | 값 |

## 3. 가설과 검정 — 실행 전에 고정

### 주가설 (둘 다, BH-FDR로 함께 보정)

**H1 — 선정 정보**: h=20에서 *B 신호 평균 순수익 − 같은 날 유니버스 전체 평균
순수익* > 0

- 날짜별 계열: 신호가 1건 이상인 날 d_t = mean(신호 순수익) − mean(그날 유니버스
  전 종목 순수익). 유니버스는 게이트 없이 **그날 구성종목 중 라벨이 있는 전부**
- 양쪽 모두 왕복 비용을 낸다 — H1은 "무엇을 고르느냐"만 잰다

**H2 — 경제성**: h=20에서 *B 신호 평균 순수익 − 같은 기간 KOSPI200 지수 수익률* > 0

- 지수 수익률 = 진입일 시가 → 청산일 종가, **비용 없음**(지수를 그냥 들고 있는
  대안). H2는 "비용을 내고도 지수보다 나은가"를 잰다

### 보조 (서술용 — 판정에 쓰지 않는다)

| ID | 내용 |
|---|---|
| S1 | h ∈ {5, 10}에서 H1 (가족별 BH-FDR, 주가설과 분리) |
| S2 | 성분 분해: RVOL 조건만 / 52주 근접 조건만 (나머지 게이트는 유지) — H1 동일 방식 |
| S3 | 안정성: 2010-2017 / 2018-2026 반기간, 코스피200 / 코스닥150 소속별 — 부호만 본다 |
| S4 | 연도별 신호 수와 d_t 평균 |

### 통계

| 항목 | 값 |
|---|---|
| 신뢰구간 | 날짜 계열의 **이동 블록 부트스트랩**, 블록 길이 = h, 4,000회, seed 20260927, 백분위 95% |
| MDE | (1.96 + 0.84) × 부트스트랩 SE |
| p값 | 부트스트랩 양측 (0을 넘는 쪽 비율 × 2) |
| 다중비교 | 주가설 {H1, H2} BH-FDR α=0.05 |

### 판정 규칙

1. 구간이 0을 제외하고 양수이며 FDR q ≤ 0.05 → `SIGNIFICANT_EDGE`
2. 구간이 0을 제외하고 **음수** → `SIGNIFICANT_NEGATIVE`
3. 구간이 0을 포함하고 |관측| < MDE → `UNDERPOWERED` ("효과 없음"이라 쓰지 않는다)
4. 구간이 0을 포함하고 |관측| ≥ MDE → `NO_SIGNIFICANT_EDGE`
5. 1이 나와도 "발견"이라 쓰지 않는다 — **"작성일 이후 데이터로 확인할 후보"**

### 하지 않을 것

- 임계값(1.5, 0.90, 10억, 5/50일, 252봉)을 결과를 보고 바꾸지 않는다
- h를 추가하지 않는다 (20 주, 5·10 보조 외 없음)
- S2·S3에서 좋은 칸을 골라 주 결과로 올리지 않는다
- 기간을 잘라 유리한 구간만 보고하지 않는다

## 4. 무엇이 나오면 무엇을 하나

| 결과 | 다음 |
|---|---|
| H1·H2 모두 `SIGNIFICANT_EDGE` | 2026-09-27 이후 신호를 전향적으로 기록(페이퍼) — 확증 단계 |
| H1만 유의 | 선정 정보는 있으나 비용·지수를 못 이긴다. 보유기간 연장·결합(A)을 **새 사전등록**으로 |
| 둘 다 `UNDERPOWERED` | 검출 가능 크기를 보고. 데이터를 늘려도 안 되면 접는다 |
| H1 `SIGNIFICANT_NEGATIVE` | 한국시장에서 B의 방향이 반대라는 기록. 스캐너에 경고로 반영 |
