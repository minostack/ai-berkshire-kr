## 3. 가설과 검정 — 실행 전에 고정

### 주가설 (BH-FDR로 함께 보정), 주 보유기간 **h = 60**

- **H1 — 선정 정보**: A 신호 평균 순수익 − 같은 날 유니버스 동일가중 순수익 > 0
- **H2 — 경제성**: A 신호 평균 순수익 − 같은 기간 KOSPI200 지수(비용 없음) > 0

날짜 계열 d_t는 신호가 1건 이상인 신호일마다 만든다(B와 같은 방식).

### 보조 (서술용 — 판정에 쓰지 않는다)

| ID | 내용 |
|---|---|
| S1 | h ∈ {20, 40}에서 H1 (가족별 BH-FDR) |
| S2 | **음의 서프라이즈**(SUE ≤ −1.0, 그 외 조건 동일)의 H1 — PEAD라면 음수여야 한다 |
| S3 | SUE 5분위(그 이벤트 전체, 게이트는 유동성·유니버스만)별 h=60 평균 초과 — 단조성만 본다 |
| S4 | 52주 근접 ≥ 0.90 / < 0.90으로 A 신호를 나눈 H1 — 한국 논문의 상호작용 확인 |
| S5 | 안정성: 2017-2021 / 2022-2026, 코스피200 / 코스닥150 소속별 — 부호만 |
| S6 | 연도별 신호 수와 평균 초과 |

### 통계 — B와 다른 점 하나

PEAD 신호는 **보고서 제출 마감일(5/15, 8/14, 11/14, 3월 말)에 몰린다.**
신호일은 연 수십 일이고, 60거래일 보유가 서로 겹친다. 그래서 날짜 단위 블록이
아니라 **신호일이 속한 달력 분기(quarter) 단위 군집 부트스트랩**을 쓴다.

| 항목 | 값 |
|---|---|
| 통계량 | 신호일 d_t의 평균 |
| 신뢰구간 | 달력 분기 군집을 복원추출, 4,000회, seed 20260927, 백분위 95% |
| MDE | (1.96 + 0.84) × 부트스트랩 SE |
| p값 | 부트스트랩 양측 |
| 다중비교 | 주가설 {H1, H2} BH-FDR α=0.05 |
| 예상 | 유효 군집이 약 38개(9.5년 × 4)라 **구간이 넓을 것이다.** `UNDERPOWERED`가 나올 가능성이 높다는 것을 미리 적어 둔다 |

### 판정 규칙 (B와 동일)

1. 구간 0 제외·양수·q ≤ 0.05 → `SIGNIFICANT_EDGE`
2. 구간 0 제외·음수 → `SIGNIFICANT_NEGATIVE`
3. 구간 0 포함·|관측| < MDE → `UNDERPOWERED`
4. 구간 0 포함·|관측| ≥ MDE → `NO_SIGNIFICANT_EDGE`
5. 1이 나와도 "발견"이 아니라 "작성일 이후 데이터로 확인할 후보"

### 하지 않을 것

- 이익 변수(영업이익)를 순이익·매출로 바꿔 다시 돌리지 않는다
- SUE 임계값(1.0), 과거 창(8/최소 4), h(60 주, 20·40 보조)를 바꾸지 않는다
- 잠정실적 공시일로 이벤트일을 바꿔 다시 돌리지 않는다(필요하면 새 사전등록)
- S2~S5에서 좋은 칸을 주 결과로 올리지 않는다
