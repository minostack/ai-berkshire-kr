## 1. 결합 정의 — 실거래로 재현 가능한 형태

| 항목 | 값 |
|---|---|
| 기저 | 사전등록 B 신호 그대로(`ab_backtest_b.build_panel`, 재신호 억제 20) |
| A 조건 | 신호일 D에 **이미 접수된** 가장 최근 분기 정기보고서의 SUE ≥ 1.0, 접수 후 60거래일 이내 — 음의 서프라이즈 필터와 같은 판정 함수(`ab_backtest_negfilter.classify`)의 부호만 뒤집은 것 |
| **A∩B** | B 신호 중 A 조건을 만족하는 것 |
| B-only | 나머지 B 신호(A 조건 불충족·SUE 없음·오래됨 포함) |
| 잠정 공시일(A2)을 쓰지 않는 이유 | A2는 SUE 확정치를 미리 보는 문제가 있다 — 실거래에서 재현 불가 |

## 2. 기간·수익률

| 항목 | 값 |
|---|---|

| 수익률·비용·유니버스 | B와 동일 |
| 보유기간 | **h ∈ {20, 60}** — B의 주 보유(20)와 A의 주 보유(60) |

## 3. 가설과 검정 — 4개를 한 가족으로 BH-FDR

| ID | 무엇 | 통계 |
|---|---|---|
| H1-20 | mean(e \| A∩B) − mean(e \| B-only) > 0, h=20 | e = 순수익 − 같은 날 유니버스 동일가중. 신호일 **달력 분기 군집** 부트스트랩 |
| H1-60 | 같은 비교, h=60 | 동일 |
| H2-20 | A∩B 순수익 − KOSPI200 > 0, h=20 | 신호일 계열 이동 블록(블록 = h) |
| H2-60 | 같은 비교, h=60 | 동일 |

공통: 4,000회, seed 20260927, MDE = 2.8 × SE.

### 판정

| H1 | 조건 |
|---|---|
| `COMBO_HELPS` | 구간 전체 > 0, q ≤ 0.05 |
| `COMBO_HURTS` | 구간 전체 < 0 |
| `UNDERPOWERED` | 구간 0 포함, \|관측\| < MDE |
| `NO_SIGNIFICANT_EDGE` | 구간 0 포함, \|관측\| ≥ MDE |

H2는 B와 같은 규칙. 어떤 유의 결과도 "전향 데이터로 확인할 후보"다.

### 미리 적는 예상

A∩B는 B 신호의 **소수**(추정 15~30%)일 것이다. 음의 서프라이즈 필터(제외군 10%)와 비슷하게
H1 구간이 넓을 가능성이 높다.

### 보조 (서술용)

| ID | 내용 |
|---|---|
| S0 | 건수: B 신호, A∩B, B-only, SUE 상태 분포 |
| S1 | A∩B와 B-only 각각의 유니버스 대비 초과(신호일 계열), h=20·60 |

### 하지 않을 것

- SUE 임계값(1.0), 최근성(60), h(20·60)를 바꾸지 않는다
- 52주 근접 임계값을 A∩B용으로 따로 조이지 않는다(B 게이트 그대로)
- 잠정 공시일 SUE를 쓰지 않는다
- S1~S3에서 좋은 칸을 주 결과로 올리지 않는다
