## 0. 한 줄 결론

**CVD·OBV 계열 지표로 매수 종목을 고르는 데서 우위를 찾지 못했다.** 네 방향
(기존 게이트 / MA20 제거 / 1분봉 전환 / 가속 재설계)을 모두 시도했고, 확립된
것은 성과가 아니라 **구조적 사실 하나**다 — "수준(level) 조건을 변화율(가속)로
바꾸면 신호가 가격 움직임 **앞**으로 온다."

| 주장 | 지위 | 핵심 근거 |
|---|---|---|
| 가속으로 바꾸면 신호가 움직임 앞에 온다 | **확립** | 신호 전 상승폭 +20.15% → **+0.25%**, 상승 종목 비율 97.8% → **55.2%**(1분봉 250일). 일봉 대리 2010~2026 20,470건에서 +0.93% / 58.0%로 재현 |
| 그 선행성이 수익으로 이어진다 | **기각에 가까움** | 일봉 대리 15.7년 D→D+2 **-0.162%**, 95% 구간 [-0.243%, -0.080%] **0 불포함**. 유니버스 대비 **16/17년 음수** |
| 기존 게이트 리스트가 순위로서 정보를 갖는다 | **미확인(약한 반대 증거)** | D+1~D+20 10개 칸 중 9개 음수. 유일하게 구간이 0을 제외한 칸(후보 전체 D+2 **-0.286%**)이 **불리한 방향** |
| 1분봉 가속 +45.1% | **판단 보류** | 거래당 95% 구간 [-0.207%, +1.683%] 0 포함, 설계 인자 민감도 -2.1%~+64.7%, 구간 특이성 유력 |

## 2. 지표 정의 (현재 코드 기준)

### 2.1 공통 — CVD 추정

체결 데이터가 아니라 **분봉 캔들에서 추정**한다(True CVD 아님).

```
hl        = 고가 - 저가
CLV       = (2×종가 - 고가 - 저가) / hl          [-1, 1]
Body      = (종가 - 시가) / hl                    [-1, 1]
direction = clamp(0.6×CLV + 0.4×Body, -1, 1)     # OHLC 비정상이면 0
Delta     = 거래량 × direction                    # = 매수량 - 매도량
normalized_delta = ΣDelta / Σ거래량               [-1, 1]
```

혼합 가중치 0.6/0.4는 **검증 전 설계값(의견)** 이다.

### 2.2 두 설계 비교

| | **수준(V1.5)** | **가속(accel-1.0)** |
|---|---|---|
| 창 | 최근 N거래일 합(기본 5, 실험 10) | 10거래일을 **최근 3 + 이전 7**로 나눔 |
| 핵심량 | `normalized_delta`(구간 합), 30분 모멘텀, 매수우위일 비율 | **가속 A = mean(f, 최근 3일) − mean(f, 이전 7일)** |
| 게이트 | 데이터품질 ×3, Δ>0, 모멘텀>0, 매수우위일 ≥50%, **종가>MA20**, **OBV 기울기>0 & OBV>MA20**, 유동성 존재 | 연속 10일 확보, **A>0**, **최근 3일 흐름>0**, 유동성 존재, **과열 제외(MA20 대비 +10% 이내)** |
| 배점 100 | CVD 40 + OBV 35 + 가격 15 + 유동성 10 − 과열 5 | 가속 60 + 최근흐름 20 + 유동성 20 |
| 의도 | 흐름이 **강한** 종목 | 흐름이 **빨라지는** 종목 |
| 부작용 | 선정 종목 97.8%가 이미 상승(D-10→D 평균 +20.15%) | 선정 종목 55.2%만 상승(+0.25%) |

가속 설계가 `종가>MA20`·`OBV>MA20`·`매수우위일≥50%`를 **일부러 뺀 것**이
설계의 핵심이다. 세 조건 모두 "이미 올랐다"를 확인한다.
`tests/unit/test_cvd_accel_scanner.py::test_MA20_아래여도_OBV가_아래여도_후보가_된다`가
이 제외를 회귀로 고정한다 — 되돌리면 테스트가 깨진다.

## 3. 검증 이력 — 무엇을 해보고 무엇이 나왔는가

### 3.1 덧붙은 사실들

- **집행 가능성**: 확정 종가(15:30) 기준 진입은 **시간외 종가매매(15:40~16:00)** 로 집행 가능하다. 동시호가 경로만 불가.
- **애프터마켓(2026-09-14~)**: 키움 `ka10080` 분봉과 `ka10081` 일봉 **모두 애프터마켓을 반영**한다 → 일봉 종가는 제도상 공식 종가가 아니라 **마지막 체결가**다(2026-09-15 삼성전자 정규장 248,500 vs 일봉 250,500, +0.80%). MA·OBV·ATR·과열 판정이 전부 이 값을 쓴다.
- **애프터마켓 유동성**: 실측 3종목에서 정규장 대비 3.2~7.2%.

## 4. 확립 / 기각 / 보류 — 지위 정리

**확립된 것 (사실)**

1. 수준 조건을 변화율로 바꾸면 신호가 움직임 앞으로 온다(1년 + 17년 재현).
2. 기존 게이트의 선정 종목은 압도적으로 **이미 오른 종목**이다(97.8~97.9%).
3. -65.6%는 종목이 아니라 **규칙**에서 나왔다(원시 D+1·D+2 ≈ 0).
4. 갭이 손절을 무력화한다(갭 74/460건 = 실현 손실의 75.1%).
5. 5분봉으로 트레일링을 평가하면 **결과가 봉 내 순서 가정에 좌우**된다(모호성 44.5%). 1분봉에서 13.3%로 줄어든다.
6. 왕복 비용 0.409%에 현재 회전율을 곱하면 **자본의 연 24~50%**다.

**기각에 가까운 것**

7. "가속의 선행성이 2거래일 수익으로 이어진다" — 15.7년 구간이 0을 제외한 음수.
8. "지표 일수를 10일로 늘리면 나아진다" — 반대였다.

**판단 보류 (데이터 부족)**

9. 1분봉 가속 +45.1%의 실체 — 구간 특이성 유력하나 직접 반증은 아니다.
10. "OBV가 가격 조건 위에 무언가를 더한다"(Stage C 후보) — 문서 작성 이후 데이터로 확증 필요.

## 6. 재발 방지 목록 — 실제로 당한 함정
