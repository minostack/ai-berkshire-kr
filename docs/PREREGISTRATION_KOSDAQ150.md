문서 버전: 1.0
작성일: 2026-09-21
상태: **실행 전 동결.** 이 문서를 고친 뒤에 돌리면 사전 등록이 아니다.
선행 문서: `PREREGISTRATION_C.md`(후보를 만든 사전 등록), `DATA_COLLECTION_PLAN.md`

## 0. 왜 또 사전 등록인가

선택지 C에서 후보가 하나 나왔다 — **PRICE+OBV가 PRICE 위에 무언가를 더한다**
(h=5 q=0.024, h=20 q=0.020). 이 후보를 확증하려면 발견에 쓰지 않은 새 표본이
**14~18년** 필요하다(`power plan`). 기다릴 수 없으므로 **같은 기간의 다른
단면**인 코스닥150에서 재현을 시도한다.

여기에 두 가지 함정이 있고, 둘 다 사후에는 막을 수 없다.

1. **재현은 확증이 아니다.** 같은 기간이므로 그 기간 고유의 우연은 그대로
   남는다. 코스닥150에서 같은 부호가 나와도 "2015~2026년에 그랬다"는 말이
   두 번 되는 것일 수 있다.
2. **표본이 두 배가 아니다.** 같은 기간의 두 유니버스는 시장 요인을 공유한다.
   ρ를 재기 전에는 얼마나 늘었는지 알 수 없다.

그래서 **무엇을 돌릴지, 무엇을 성공이라 부를지, 무엇을 하지 않을지**를 먼저
적는다.

## 1. 새로 확인된 사실 — 계획이 바뀐 부분

2026-09-21에 `idx/kosdaq_dd_trd` 구독이 열렸다. 열고 나서 실측한 것들이
원래 계획의 전제 두 개를 깼다.

| 항목 | 원래 전제 | **실측 (2026-09-21)** |
|---|---|---|
| 재현 패널 길이 | 2010~2026, 약 16년 | **2015-07-13~, 약 11.2년** |
| 섹터 분해로 변경일 좁히기 | 코스피200처럼 가능 | **불가** — 섹터 7종 합이 지수보다 1.2% 부족 |
| 전체 가산 항등식 | 확인 필요 | **성립** — `코스닥 (외국주포함)` = 전 종목 합, 오차 **0원** |
| 종목별 시세 | 확인 필요 | 성립 — `sto/ksq_bydd_trd` 1,820종목 |

**코스닥150 지수는 2015-07-13에 처음 나온다.** 2015-07-10까지는 없다. 섹터
7종은 2016-01-04에 없고 2018-01-02에 있다.

결과적으로 **재현 패널은 코스피200 패널(4,114거래일)의 약 68%**다. 이 문서의
검정력 계산은 전부 그 길이를 전제로 한다.

## 2. 가설 — 1차 하나, 부차 둘

### H1 (1차, 확증적 방향 검정)

> 코스닥150 2015-07-13~2026-09-18 구간에서, **PRICE+OBV의 평균 순수익이
> PRICE보다 크다.**

- **단측이다.** 선택지 C에서 방향(양)을 이미 봤으므로 방향을 건다. 반대로
  나오면 그것으로 끝이고, 사후에 양측으로 바꿔 읽지 않는다.
- 이것이 **유일한 1차 검정**이다. 다중비교 보정은 1차 검정에 적용하지
  않는다(검정이 하나뿐이므로).

### H2 (부차) — 의존성

> 코스피200과 코스닥150의 일별 delta 계열 상관 ρ는 얼마인가.

판정이 아니라 **측정**이다. H1의 해석을 바꾸므로 H1과 함께 보고한다.

### H3 (부차) — 유동성 조건

> 코스닥150에서도 `cond_liquidity`가 판정 가능한 행에서 한 번도 거짓이
> 되지 않는가.

코스피200에서는 선택 집합을 **전혀** 바꾸지 않았다. 코스닥은 소형주가 많아
다를 수 있다. 다르다면 그 자체가 설계 정보다.

## 3. 방법 — 실행 전에 고정

| 항목 | 고정값 |
|---|---|
| 유니버스 | 코스닥150, 실제 과거 이력(스냅샷 아님) |
| 기간 | 2015-07-13 ~ 2026-09-18 |
| 1차 지표 | **평균 순수익 차이**(비용 후), 단위 %p |
| 1차 보유기간 | **h=20** |
| 부차 보유기간 | h=5 (보고는 하되 1차 판정에 쓰지 않는다) |
| 대비 | `PRICE+OBV` vs `PRICE` (중첩, 같은 날짜 짝지음) |
| 구간 | 블록 부트스트랩(블록 20) 과 군집강건(CR1) 중 **넓은 쪽** |
| 부트스트랩 | 반복 2,000, seed **20260921** |
| 검정 | 단측 α = 0.05 |
| 비용 | `configs/costs/krx_v1.json`, 코스닥 수수료·세율로 별도 확인 후 고정 |
| 결측·상장폐지 | 상장폐지 종목 포함. 진입가 없으면 그 신호는 label NULL, 표본에서 제외 |
| 부분 유니버스 | 그날 구성종목 검산이 0원이 아닌 날짜는 **제외**하고 제외 일수를 보고 |
| 의존성 | `dependence measure` — 같은 날짜 블록 동시 재표집, 블록 20 |

**격자는 이게 전부다.** 다른 조합·다른 보유기간·다른 지표를 추가로 돌리지
않는다.

## 4. 판정 규칙

### 4.1 H1 — 세 가지 중 하나

| 판정 | 조건 |
|---|---|
| **재현됨** | 단측 p < 0.05 **이고** 부호가 양 **이고** 관측 효과가 그 표본의 MDE80 이상 |
| **재현 실패** | 부호가 음이거나, 단측 p ≥ 0.05인데 MDE80을 넘는 크기를 잴 수 있었던 경우 |
| **판정 불가** | 위 어느 쪽도 아닌 경우 — 주로 검정력 부족 |

**"판정 불가"를 실패로도 성공으로도 쓰지 않는다.** Stage 8에서 배운 것이
이것이다.

### 4.2 ρ가 결론을 어떻게 바꾸는가

ρ는 **점 추정이 아니라 신뢰구간**으로 읽는다. `dependence measure`가 내는
판정을 그대로 쓴다.

| ρ 구간 판정 | H1이 "재현됨"일 때의 해석 |
|---|---|
| `INDEPENDENT_ENOUGH` (상한 < 0.3) | 두 단면에서 독립적으로 나왔다. 재현의 가치가 가장 크다 |
| `DEPENDENT_USE_JOINT` (그 사이) | 결합 추정과 **유효 독립 표본 수**를 함께 보고한다. "표본 두 배"라고 쓰지 않는다 |
| `REDUNDANT` (하한 > 0.7) | **재현으로 치지 않는다.** 같은 것을 두 번 본 것이다 |
| `RHO_UNCERTAIN` | ρ조차 못 재는 자료다. **H1 결론을 미룬다** |

### 4.3 재현돼도 "발견"이라 쓰지 않는다

선택지 C와 같은 규칙이다. 재현은 **후보의 지위를 올릴 뿐**이고, 확증은
여전히 새 기간에서만 가능하다. 통과하면 후보 상태에 "코스닥150에서 재현됨
(ρ=…)"을 덧붙인다.

### 4.4 경제성 게이트를 함께 통과해야 한다

통계만으로 통과시키지 않는다. `candidate gate`의 다섯 축을 적용하고
**떨어진 축을 그대로 보고**한다. 참고로 코스피200 후보는 지금
**통계(관측/MDE 0.86~0.97)와 경제성(비용 후 연 37bp)에서 이미 떨어진다.**
코스닥150에서 재현돼도 이 두 축이 해결되는 것은 아니다.

## 5. 하지 않을 것

- **유의한 칸을 찾은 뒤 연도·국면·시총으로 쪼개지 않는다.** 쪼개면 반드시
  "어떤 해에 몰려 있다"가 나온다.
- **문턱(0.3 / 0.7 / 연 100bp)을 결과를 보고 옮기지 않는다.**
- **h=1을 되살리지 않는다.**
- **섹터 검산을 쓰지 않는다.** 코스닥150에서는 가산성이 깨져 있다. 코드가
  거부하도록 해 뒀다(`sector_caps`).
- **코스닥150 명단을 `data/index_stocks.json`에서 가져오지 않는다.** 그
  파일의 코스닥150 항목은 2026-09-21 검산에서 공식 지수 대비 **−88.8%**로
  틀린 것이 확인됐다. 유니버스는 Stage 3 복원 경로로 새로 만든다.

## 6. 실행 순서

```bash
# 1) 유니버스 복원 (검산 0원이 아닌 날은 기록하고 제외한다)
python cvdobv.py universe krx-cache --market KOSDAQ150 --start 2015-07-13
python cvdobv.py universe notices  --market KOSDAQ150
python cvdobv.py universe rebuild  --market KOSDAQ150
python cvdobv.py universe verify   --market KOSDAQ150

# 2) 일봉·feature·label
python cvdobv.py daily-cache build --market KOSDAQ150
python cvdobv.py features build    --market KOSDAQ150
python cvdobv.py forward build     --market KOSDAQ150

# 3) H1 — 1차 검정 (이 한 줄이 전부다)
python cvdobv.py daily-gate backtest --market KOSDAQ150 \
  --base-variant PRICE --variants PRICE,PRICE+OBV \
  --horizons 5,20 --outcomes up \
  --out reports/prereg-kosdaq150/h1-nested-price.json

# 4) H2 — 의존성 (H1 결과 해석 전에 반드시)
python cvdobv.py dependence measure \
  --series-a reports/prereg-c/h1-nested-price.series.json \
  --series-b reports/prereg-kosdaq150/h1-nested-price.series.json \
  --block-length 20 --seed 20260921 \
  --out reports/prereg-kosdaq150/h2-dependence.json

# 5) 게이트
python cvdobv.py candidate gate \
  --candidates reports/prereg-kosdaq150/candidates.json \
  --out reports/prereg-kosdaq150/gate.json
```

> **`--market` 옵션은 아직 없다.** 현재 CLI는 코스피200을 전제한다. 이 순서를
> 실행하려면 유니버스·일봉·feature 경로에 시장 인자를 먼저 넣어야 한다.
> `KrxOpenApi`는 2026-09-21에 `Market`으로 일반화했으므로 그 위에 붙이면 된다.
> **이 문서는 그 작업이 끝나기 전에 동결된 것이고, 코드가 준비됐다고 해서
> 여기 적힌 격자나 판정 규칙을 고치지 않는다.**
