# CVD 종가매수 종목 선정 스캐너 — `cvdsel-2.0`

전략 명세 `CVD_stock_selection_strategy.md` v2.0(2026-10-23)의 **종목 선정**만 구현한다.
매수 주문·청산(-5% 손절, +8% 활성 / 고점 대비 -4% 트레일링)·자금 관리(7·8·10장)는
별도로 진행하므로 이 디렉토리에 없다.

기존 스캐너(`tools/`)와 섞지 않으려고 별도 디렉토리에 두었다. 데이터는 **기적재분만**
읽는다 — API 호출 없음, 저장소 쓰기 없음.

## 실행

```bash
python -m cvd_selection.scan                       # 최근 일봉 거래일
python -m cvd_selection.scan --as-of 2026-10-22 --save
python -m cvd_selection.scan --show-rejects 20     # 근접 탈락 종목 사유
python -m pytest cvd_selection/tests -q            # 단위 테스트
```

`--save`는 `cvd_selection/output/cvdsel-<D>-<run_id>.json|csv`에 쓴다. 실행마다 새
파일이라 이전 스냅샷을 덮지 않는다(명세 3.2-5). 351종목 1회 약 1분.

## 데이터 매핑

| 명세 | 이 구현 | 원천 |
|---|---|---|
| B, S (D-5..D-1 확정) | KIS 일별 매수·매도 체결량, **확정 행만**(16:10 잠정 행은 탈락 사유) | `sides_flow.read_sides_flow` (sides-1.0, UN=KRX+NXT) |
| U 미분류량 | **없음** → Vflow = B + S | — |
| D 일봉(C, H, L) | 16:10 잠정 봉(1분봉 합) 또는 확정 봉 | `read_standard_daily` (bars-1.0) |
| V_D, 과거 V, A (RVOL·AVG_A20) | **1분봉 범위** 거래량·거래대금 — KRX(애프터마켓 제외) + 2026-08-03부터 NXT 메인. 블록딜 제외(명세 3.1) | `data.load_minute_day_totals` (`silver.minute_bars`) |
| VWAP_D | Σ거래대금 / Σ거래량 — D 1분봉 KRX 09:00~15:30(종가 단일가 봉 포함) + NXT 메인 09:00~15:30. 봉 거래대금 = KIS 누적거래대금 직전 봉 차이 | `silver.minute_bars` `traded_value`·`cum_traded_value` |
| P_start, P_end | KRX 1분봉 [14:50, 15:20) 첫 시가·마지막 종가 | 같음 |
| 구성종목 | `universe_on(D)` | universe-1.0 |

## 명세와 다른 점 (데이터 한계 — 결과 JSON `data_scope`에도 남는다)

1. **체결량 세션 범위**: UN 체결량은 KRX·NXT의 모든 세션(프리·애프터 포함)을 담는다.
   명세는 메인마켓만이다. 시장별(KRX/NXT) 분리도 2026-10-20부터는 매일 받지 않는다.
2. **미분류량 없음**: 공급자가 주지 않아 Vflow = B + S이고, 미분류율 5% 제외 기준은 적용하지 못한다.
   DR은 명세 정의보다 분모가 작아 절댓값이 커질 수 있다.
3. **VWAP (2026-10-24)**: KIS 1분봉 누적거래대금(`acml_tr_pbmn`)의 직전 봉 차이인 봉 거래대금으로
   Σ대금/Σ수량을 낸다(`vwap_method=EXACT_CUM_VALUE`). 범위는 KRX 정규장 1분봉(09:00~15:30 종가
   단일가 봉, 15:31~15:34에 늦게 찍힌 종가 체결 포함) + NXT 메인. 15:35 이후 시간외 종가 봉은 넣지 않는다.
   - 거래대금 없는 봉(키움에만 있고 KIS가 주지 않은 봉)은 분자·분모에서 함께 빼고
     `VWAP_UNVALUED_EXCLUDED=<주식수>`를 단다. 그 거래량이 범위의 0.1%(`vwap_max_unvalued_share`)를
     넘으면 품질 탈락(`VWAP_VALUE_MISSING`). 2026-10-22: 2종목이 NXT 1봉(10주·3주)만 빠짐
   - **누적거래대금이 없는 2025-10-15 전 날의 사후 실행**은 대표가격 (H+L+C)/3 가중으로 추정한다
     (`vwap_method=ESTIMATED_TYPICAL_PRICE`, 플래그 `VWAP_ESTIMATED`, 머리말에 종목 수 표시).
     당일 실행·2025-10-15 이후 날에는 추정하지 않는다. 추정과 정확값의 차이는 2026-10-22·23
     실측 중앙 1.4~1.8bp, 95% 5.7bp 이하, 최대 39bp
   - 2025-10-15(KIS 지평 첫날)은 적재기가 첫 봉 거래대금을 비워 두었다. 다른 날과 같은 정의
     (첫 봉 거래대금 = 그날 첫 누적값)로 채운다
   - 한계: KRX 첫 봉(09:00) 누적값에 봉 거래량에 없는 체결이 섞인 날이 있다(2026-10-22 351종목 중
     23종목, 누적/수량이 봉 고저 밖). 장전 시간외 체결로 추정. 초과 대금은 그 종목 정규장 대금의
     0.009~0.37%로 VWAP을 그만큼 높인다 — 분리할 정보가 없어 보정하지 않았다
4. **거래량 범위 (2026-10-24 변경)**: RVOL·AVG_A20은 일봉이 아니라 **1분봉 범위**의 거래량·거래대금을
   쓴다 — D와 과거 20일이 같은 정의다. 확정 일봉에는 1분봉·누적거래대금·KIS 체결량 어디에도 없는 물량
   (시간외 대량매매 = 블록딜 추정)이 들어 있다. 명세 3.1은 이를 선정 거래량에서 빼라고 한다.
   예: 한화오션 2026-10-19 일봉 2,346만 주 중 1분봉 범위 129만 주 — 그 날이 과거 20일 평균을
   키워 RVOL을 0.52배로 눌렀었다.
   - 범위 = KRX 1분봉 중 애프터마켓(AFTER)을 뺀 봉(정규장·늦은 종가 체결·15:35 장후 시간외 종가 봉)
     + **2026-08-03부터**(bars-1.0 경계, 2026-10-29에 9/14에서 옮김) NXT 메인 09:00~15:30. NXT 포함 여부는 일봉 표시가 아니라 날짜로 정한다
     (16:10 잠정 봉과 확정 봉에서 같은 범위). 그 전 날은 NXT가 빠져 있어, 비교 구간이 경계를
     넘으면 `VOLUME_SCOPE_CHANGE_IN_WINDOW`를 단다
   - 거래량 = min(일봉, 1분봉 합). 키움 1분봉이 일봉보다 큰 날(2025-09 한화 등)은 일봉으로
     자르고 `MINUTE_OVER_DAILY=<날짜>`
   - 1분봉은 원주가다. 일봉 종가와 1분봉 마지막 종가가 5% 넘게 다르면 수정 계수로 보고 거래량을
     그 계수로 바꾼다(`MINUTE_VOLUME_ADJUSTED=<날짜>`, 액면분할 등이 20일 창에 걸친 경우)
   - 거래대금 = 1분봉 누적거래대금 차이 합. 15:35 장후 시간외 종가 봉(키움만 줌, 대금 없음)은
     그 시간 체결이 전부 당일 종가라 거래량 × 종가로 정확히 채운다. 그 밖에 대금 없는 봉은
     (H+L+C)/3 × 거래량으로 채우고, 그 거래량이 0.1%를 넘는 날이 하나라도 있으면 `avg_a20_est`.
     2025-10-15 전 날(누적거래대금 없음)은 전부 추정 — 2025-10-01 사후 실행에서 348/351종목
   - 1분봉 범위 합계가 없는 날이 D 또는 과거 20일에 있으면 품질 탈락(`MINUTE_VOLUME_MISSING`)
   - 결과에 `volume_total`(일봉)·`volume_basis`(1분봉 범위)·`volume_basis_excluded`(뺀 물량)를 함께 남긴다
   - 한계: 1분봉이 체결 일부를 빠뜨린 날(일봉 표시 `MINUTE_REGULAR_VOLUME_GAP`, bars-1.0 실측 하위 1%
     0.77배)은 그만큼 같이 빠진다. 블록딜과 구분할 데이터가 없다
   - 영향(1년, 7.99만 종목·거래일, 변경 전 측정): RVOL 1.3 판정 0.78%, AVG_A20 100억 판정 0.22%가
     바뀌었다. 변경 전 당일 실행은 D만 블록딜이 빠져 RVOL이 아래로만 치우쳤다(0.47%) —
     `분석-거래량기준-블록딜-영향-20261024.md`
   - NXT 거래 종목인데 D의 NXT 거래량을 못 받았으면(`NXT_VOLUME_MISSING`) 품질 탈락
5. **D 일봉 거래량·거래대금**: 출력(`volume_total`, `turnover_total`)에만 남기고 판정에는 쓰지 않는다.
6. **수정주가 (2026-10-26)**: 일봉은 수정주가, 1분봉은 원주가다. D 뒤에 권리락·분할이 생긴 뒤 사후 실행하면
   일봉 종가와 KRX 마지막 1분봉 종가가 어긋난다(예: 엘앤씨바이오 2026-10-23 일봉 30,149원 vs 1분봉 60,000원,
   일봉 표시 `MINUTE_PRICE_RESCALED`). 5% 넘게 다르면 수정 계수로 보고 VWAP·HoldClose 계산의 1분봉 가격에
   곱한다(`MINUTE_PRICE_ADJUSTED=<계수>`, 결과 열 `minute_price_factor`). 거래량 쪽은 4절 `MINUTE_VOLUME_ADJUSTED`
7. **선정 시각**: 명세는 15:35지만 D 일봉(잠정)은 **16:10 적재 뒤**에 생긴다. 그래서 지금
   적재 일정으로는 NXT 종가매매(15:30~16:00)·장후 시간외 종가(~16:00) 시간 안에 결과를 낼 수
   없다. 15:35 실행을 하려면 15:30 직후 1분봉·잠정 봉 적재가 따로 필요하다(매매 단계 과제).
8. **사후 실행**: `--as-of`로 과거 날을 돌리면 체결량 `available_at`이 소급 적재 시각이라
   선정 시각 뒤일 수 있다. 사후 실행은 `FLOW_AVAILABLE_AFTER_DECISION` 표시만, 당일 실행은 탈락.
   D 일봉이 이미 확정이면 15:30 스냅샷이 아닌 확정본으로 재현된다(머리말에 잠정/확정 수 표시).
9. **미구현**: 관리종목·투자경고 상태, 업종 한도(업종 데이터 없음), 보유 중복·총 5종목 한도
   (매매 단계), 9장 익일 대사(잠정 vs 확정 차이 기록).

## 판정 순서

- **품질**: D 일봉 존재·거래량>0, 유효 일봉 ≥60, 직전 20거래일 결측 없음(일봉·1분봉 범위 합계), D-5..D-1 확정 체결량
  전부, D KRX 1분봉 존재, 마감 30분 봉(수집 기록 없이 빠진 분이 있으면 무거래·누락 구분 불가 → 탈락),
  CLV 정의 가능
- **필수 조건(5장)**: AVG_A20 ≥ 100억, C > MA20 > MA60, MA20 > MA20(D-5), DR5 ≥ 5%, POS5 ≥ 3,
  DR2 > 0, Delta(D-1) > 0, RVOL ≥ 1.3, CLV ≥ 0.70, 0 < GAPVWAP ≤ 5%, Rlate ≥ 0,
  HoldClose ≥ -0.5%, ATRP14 ≤ 4%
- **점수(6장)**: DR5 15/20/25, POS5 10/15/20, RVOL 5/10/15, CLV 5/10/15, 돌파(C > HH20_prev) 15 / 5,
  VWAP 이격 10/5 — 동점은 DR5 → AVG_A20 → 코드. 상위 3종목에 ★

모든 조건을 끝까지 매겨 탈락 사유를 전부 남긴다(첫 사유만이 아니라). 진단·임계값 검증용이다.
