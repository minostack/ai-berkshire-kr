# CVD/OBV 기반 당일 투자 후보 스캐너

키움증권 REST API로 코스피200 / 코스닥150 종목의 분봉·일봉을 수집해서
CVD(Cumulative Volume Delta)와 OBV(On-Balance Volume)를 계산하고
스코어 상위 종목을 출력합니다. (도구 버전 **V1.5** — KRX 애프터마켓 대응)

---

## ⚠ 먼저 읽을 것 — 두 설계가 있고, 둘 다 수익은 미검증입니다

| 설계 | 도구 | 무엇을 보는가 | 검증 상태 |
|------|------|--------------|----------|
| **수준(level)** | `tools/kiwoom_cvd_obv_scanner.py` (V1.5) | 종가>MA20, OBV>MA20, 매수우위일≥50% — **이미 오른 것** | **순위로서의 정보 미확인.** D+1~D+20 어느 지평에서도 유니버스를 못 이겼고, 후보 전체 D+2 초과수익 **-0.286%(신뢰구간 0 제외)** |
| **가속(accel)** | `tools/cvd_accel_scanner.py` (신규) | 일별 CVD 흐름의 **변화율** — 아직 안 오른 것 | **선행성만 확립**(신호 전 상승폭 +20.15%→+0.25%). **수익 미확립** — 거래당 95% 구간 0 포함, 일봉 대리 15.7년 D→D+2 -0.162% |

- 측정 근거: `reports/종목검색-지표-리서치-20260927.md` §1,
  `reports/CVD-가속설계-검증-20260927.md`,
  `reports/CVD-가속-일봉대리-장기검증-2010-2026-20260927.md`
- **두 리스트 모두 단독 매매 근거로 쓰지 마세요.** V1.5 리스트는 유동성·데이터
  품질 필터로는 여전히 유효하지만, "이 종목이 오를 것"이라는 근거는 측정으로
  확인되지 않았습니다.
- V1.5는 **해시로 동결된 기준 구현**입니다(`data/manifests/baseline_v1_5.json`,
  골든 회귀 `tests/regression/test_v15_golden.py`). 가속 설계를 이 파일에 넣지
  않고 별도 도구로 만든 이유입니다 — 고치면 지금까지의 백테스트가 어느 코드로
  나온 것인지 흔들립니다.

**지원 입력 형식**:

```
/cvd-obv-scan                              # 코스피200 기본 스캔 (5일, 5분봉, 상위15)
/cvd-obv-scan kospi200                     # 코스피200 상위 15개
/cvd-obv-scan kosdaq150                    # 코스닥150 상위 15개
/cvd-obv-scan both                         # 코스피200 + 코스닥150 동시
/cvd-obv-scan kospi200 --days 10           # 10영업일 CVD
/cvd-obv-scan kospi200 --top 20            # 출력 종목 수 변경(기본 15)
/cvd-obv-scan kospi200 --period 1          # 1분봉 (더 정밀)
/cvd-obv-scan kospi200 --session after     # 애프터마켓(16:00~20:00) 기준 저녁 스캔
/cvd-obv-scan detail 009150                # 단일 종목 상세 분석
/cvd-obv-scan update-index                 # 종목 목록 최신화

/cvd-accel-scan                            # ← 가속 설계는 별도 스킬 (1분봉)
```

> **봉 기준 `bars-1.0`** (`docs/BAR_STANDARD.md`) — 실행 입구는 `tools/cvd_obv_scan.py`다.
> 계산은 동결된 V1.5(`tools/kiwoom_cvd_obv_scanner.py`) 그대로이고, 봉만 기준에 맞춰
> 넣는다: 일봉 = 로컬 정규장·수정주가 일봉, 분봉 = 1분봉을 받아 `--period`분봉으로
> 합성, 일봉 완료 = 15:35(`--daily-scope regular`). V1.5 파일을 직접 실행하면 일봉이
> 애프터마켓 포함(EXTENDED)이라 다른 스캐너와 기준이 달라진다.
>
> 사전 조건: 로컬 일봉 최신화 — 16:10 잠정 `data-load provisional` + 익일 08:30 확정 `data-load daily`(작업 스케줄러 자동).

### 2단계: 분봉 수집 (키움 ka10080 1분봉 → `--period`분봉 합성) — 세션 분류

| 파라미터 | 값 | 설명 |
|---------|-----|------|
| `stk_cd` | 종목코드 | 6자리 |
| `tic_scope` | 1 | 항상 1분봉으로 받는다. `--period`(기본 5)는 계산 해상도 — 1분봉을 합성(키움 원본 5분봉 대비 99.99% 일치) |
| `upd_stkpc_tp` | 1 | 수정주가 적용 |

- 연속조회(`next-key`/`cont-yn` **헤더**)로 페이지네이션
- 각 봉에 `bar_start`/`bar_end`/`session` 부여
- **기준시각(as_of) 이후이거나 아직 끝나지 않은 봉(`bar_end > as_of`)은 제외** —
  스캔 도중 뒤에 조회된 종목이 더 최신 데이터로 평가되는 문제 방지
- 기대 봉 수(실측 기준): 정규장 `ceil(380/주기) + 15:30 단일가 봉`,
  애프터마켓 `ceil(240/주기)`
  → 5분봉 77/48, 1분봉 381/240, 30분봉 14/8, 60분봉 7/4
  (15:20~15:30 종가 단일가 구간에는 접속 체결이 없어 봉이 생기지 않는다)

---

### 3단계: CVD 계산 (세션별 분리)

분봉 캔들에서 매수/매도 체결을 **추정**해 누적합니다(체결 데이터 아님).

```
CLV       = (2×Close - High - Low) / (High - Low)     [-1, 1]
Body      = (Close - Open) / (High - Low)             [-1, 1]
Direction = 0.6×CLV + 0.4×Body        (혼합 가중치는 초기 설계값)
Delta_est = Volume × Direction

normalized_delta = ΣDelta / ΣVolume   (-1~1, 종목 간 비교 가능)
```

- 정규장 CVD와 애프터마켓 CVD를 **따로** 계산해 함께 출력
- **모멘텀**: 목표 30분을 실제 시간 구간으로 계산. 같은 거래일·같은 세션
  안에서만 자른다
  - `SUCCESS` 구간 확보 / `WARMING_UP` 구간 부족(장 초반 등) /
    `RESOLUTION_LIMITED` 분봉 주기가 30분보다 김(예: 60분봉)
- **매수우위일 비율**: 완료된 세션만으로 계산하고, 완료 거래일이 2일 미만이면
  점수·Gate에 사용하지 않는다(당일 장중 값으로 폴백하지 않음)

---

### 4단계: OBV·가격추세·유동성 (로컬 정규장 일봉, 220캘린더일)

```
종가 상승 → 거래량 더함 / 하락 → 뺌 / 보합 → 유지

normalized_slope = OBV 변화량 / 구간 거래량   (-1~1)
MA20/60/120 위치·기울기·정배열, ATR14(Wilder), 20일 평균 거래대금(근사)
```

일봉은 **정규장 봉**이다(봉 기준 `bars-1.0`). 2026-09-14 이후 키움 일봉은 종가가
애프터마켓 최종가(20:00)라, 로컬 저장소의 1분봉 정규장 복원본을 쓴다. 당일 봉은
15:35~16:00에 실행하면 API에서 받은 정규장 확정값을 붙이고, 그 밖의 시각에는 로컬에
있는 것까지만 쓴다. 완료 시점은 `--daily-scope regular`(15:35)로 자동 지정된다.

| 값 | 확정 시각 | 설명 |
|----|----------|------|
| `regular`(입구 기본) | 15:35 이후 | **기준** — 정규장 일봉이므로 |
| `auto`/`extended` | 20:05 이후 | V1.5 원래 동작(애프터마켓 포함 일봉). 2026-10-03 이전 결과 재현용 |

> 정규장 복원 전인 날(대개 20:05 전에 적재한 오늘)은 일봉 계산에서 빠지고, 실행
> 끝에 `⚠ 정규장 복원 전인 날…`로 표시된다. `detail`의 `[종가 정의 확인]`에서
> 정규장 마지막 분봉 종가와 일봉 종가가 같은지(+0.00%) 확인할 수 있다.

---

### 5단계: 점수(100점) + Absolute Gate

**총점(상대 강도, 스캔 유니버스 내 백분위)** — 잠정 가중치·의견

| 항목 | 배점 |
|------|------|
| CVD 정규화 Delta 백분위 | 20 |
| CVD 정규화 모멘텀 백분위 | 10 |
| 매수우위일 비율 백분위(정규장 완료 거래일) | 10 |
| OBV > OBV MA20 (절대) | 15 |
| OBV 정규화 기울기 백분위 | 20 |
| 가격추세(MA20 상회 5 + MA20 상승 4 + MA60 상회 3 + 정배열 3) | 15 |
| 유동성(20일 평균 거래대금 백분위, 결측 0점) | 10 |
| 과열 페널티(종가가 MA20 대비 +15% 초과 이격) | -5 |

백분위 모집단은 해당 지표 `data_status == SUCCESS` 종목만 포함합니다.

**Absolute Gate(총점과 별개, 절대 기준)**

- `🟩 BUY_CANDIDATE`: 데이터 품질 충족 + 정규화 Delta > 0, 정규화 모멘텀 > 0,
  정규장 매수우위일 비율 ≥ 50%, 종가 > MA20, OBV 기울기 > 0 & OBV > MA20,
  유동성 데이터 존재
- `🟨 WATCH`: 데이터는 충분하나 절대조건 일부 미충족(사유 표시)
- `⬜ DATA_INSUFFICIENT`: CVD/OBV/가격추세 중 데이터 품질 미충족

`--session after`면 여기에 **애프터마켓 조건**이 추가됩니다: 애프터마켓
데이터 품질 SUCCESS, 최근 세션일 거래대금 > 0, 세션이 열려 있는 동안에는
마지막 봉이 최근(max(2×분봉주기, 10분) 이내). 수치 임계값은 검증 전이라
부호(>0)와 최신성만 봅니다.

정렬은 **상태 → 총점** 순입니다(총점이 더 높아도 Gate 미통과면 아래로 내려갑니다).
다이버전스(endpoint·Pivot)는 전부 참고용이며 배점에 반영하지 않습니다.

리포트에는 **상위 15종목**을 싣고, 각 지표(총점·정규화Δ·모멘텀·bull%·MA20 이격·
거래대금)의 정의와 "어떤 값이 좋은가"를 함께 기록합니다 —
예시: `reports/daily-scan/cvd-obv-kospi200-20260916.md` 3절.

## CVD 가속 스캔 — 별도 스킬입니다

가속 설계(1분봉, 일별 흐름의 변화율)는 **`/cvd-accel-scan`** 으로 옮겼습니다.
정의·게이트·배점·출력 해석은 그 스킬 문서 하나만 보면 됩니다
(`skills/cvd-accel-scan.md`) — 같은 내용을 두 곳에 두면 한쪽이 먼저 낡습니다.

```bash
python3 tools/cvd_accel_scanner.py scan --index both --top 15 --save-json
python3 tools/cvd_accel_scanner.py detail --code 005930
```

요약: 게이트는 `A>0`, `최근 3일 흐름>0`, 연속 10거래일 확보, 유동성 존재,
`MA20 대비 +10% 이내`. `종가>MA20`·`OBV>MA20`·`매수우위일≥50%`는 **일부러
제외**했습니다(회귀 테스트로 고정). 배점은 가속 60 + 최근흐름 20 + 유동성 20.

## 주요 주의사항

1. **실행 시점별 의미**
   - 장 초반(09:00~09:30)에는 30분 모멘텀 구간이 없어 `WARMING_UP`으로 표시되고
     Gate를 통과하지 않습니다 — 결함이 아니라 데이터가 아직 없는 것입니다
   - 15:35 이후 정규장 세션이 확정되고, 애프터마켓 세션은 20:05 이후 확정됩니다
   - 당일 정규장 일봉은 15:35~16:00 실행에서 API로 붙고, 16:10 뒤에는 로컬 잠정 봉
     (`data-load provisional`, 거래량 근사), 익일 08:30 뒤에는 확정 봉이 읽힌다
2. **CVD는 근사값** — 틱 데이터가 아닌 분봉 캔들 추정이므로 절대값보다
   **방향과 다이버전스**가 중요합니다
3. **애프터마켓 데이터 없음 ≠ 매도세 없음** — 거래 대상 제외 / 무체결 /
   API 미제공을 이 데이터만으로는 구분할 수 없습니다(상태만 구분해 표시)
4. **일봉 종가 = 정규장 종가(15:30)** — 봉 기준 `bars-1.0`. 키움 원본 일봉은
   2026-09-14부터 애프터마켓 최종가라, V1.5를 직접 실행한 과거 결과(2026-10-03 전)와는
   종가 정의가 다릅니다. 두 결과를 같은 표에 섞지 마세요
5. **애프터마켓 유동성은 정규장보다 훨씬 얕습니다** — 같은 임계값·RVOL 기준을
   그대로 적용하지 마세요. 실측 표본(3종목)의 애프터마켓 거래량 비중은 정규장
   대비 3.2~7.2%였고, 제도 시행 초기라 비교할 역사 데이터도 부족합니다
6. **API 호출 제한**: 초당 5회 — 200개 전종목 스캔 시 약 1~2분 소요.
   애프터마켓 포함으로 하루 분봉이 +61% 늘어 20영업일 요청은 페이지가 하나 더 듭니다
7. **종목 목록 갱신**: 코스피200/코스닥150 정기 변경 시 `update_index.py` 재실행
8. **가중치·임계값은 검증 전 설계 가설(의견)입니다** — 백테스트로 확정된 값이 아닙니다
9. **V1.5 리스트는 "오를 종목"의 근거가 아닙니다** — 250거래일 실측에서
   D+1~D+20 어느 지평도 유니버스를 이기지 못했고, 유니버스를 이긴 날이
   38.9~49.2%였습니다. 유동성·데이터 품질 필터로는 계속 유효합니다
   (`reports/종목검색-지표-리서치-20260927.md` §1)
10. **가속 리스트는 "덜 늦은 리스트"까지만 검증됐습니다** — 선행성은
    17년간 재현되지만 수익은 재현되지 않았습니다. 일봉 대리 15.7년은 음수입니다
11. **이 스캔 결과는 투자 권유가 아닙니다** — 반드시 심층 분석 후 최종 판단
