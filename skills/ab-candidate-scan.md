| 후보 | 지표 | 근거 | 보유 |

| **B** | 거래량 급증(RVOL) + 52주 신고가 근접 | Gervais·Kaniel·Mingelgrin(JF 2001), George·Hwang(2004) | 20거래일 |

### 스캔 전 데이터 갱신 (순서가 중요)

```bash
# 1) 구성종목 명단 — 6·12월 정기 변경 후에만 (유니버스 이력 기준, /update-index)
python tools/update_index.py

# 2)·3) 일일 적재 — 봉 기준 bars-1.0(docs/BAR_STANDARD.md). 1분봉 → 일봉 → 정규장 일봉
#    복원을 이 순서로 한 번에 한다. 애프터마켓 확정(20:05) 뒤에 돌린다(스케줄 익일 08:30,
#    scripts/daily-load.bat. 16:10에는 data-load provisional이 오늘 잠정 일봉을 만든다).
#    마지막 확정일 이후 빠진 날을 스스로 채운다. run-id는 자동(UTC 시각)
python cvdobv.py data-load daily

# 4) 스캔
python tools/ab_candidate_scanner.py
```

- 일봉 수집 대상은 `data/index_stocks.json`이다. 명단이 유니버스와 어긋나면 해당 종목이
  **조용히 평가에서 빠진다**(2026-09-23에 39종목). 출력의 `평가 N`이 유니버스(351)보다
  눈에 띄게 적으면 명단부터 확인한다
- 기준 일봉은 정규장 봉만이다. 정규장 복원 전인 날은 평가에서 빠지고 "정규장 복원 전인
  날이 있다" 경고가 나온다. 수십 종목 이상이면 2)·3)을 빠뜨린 것이다(또는 20:05 전에
  돌렸다). 몇 종목만 남는 것은 정상이다 — 분봉에 종가 단일가 봉이 없는 날은 정규장
  종가를 알 수 없어 만들지 않는다(2026-09-14~10-01: 4,212봉 중 10봉)
- **16:10~익일 08:30 사이 실행은 기준일 봉이 잠정**(1분봉 합, 거래량 근사)이다. 스캐너가
  "기준일 일봉이 잠정" 경고를 내고 스냅샷에 `provisional: true`를 남긴다. B는 RVOL
  1.25~1.8 구간(게이트 ±20%) 종목을 "확정 뒤 빠질/들어올 수 있음"으로 따로 표시한다
  (`B_provisional_watch`). 실측: 10/14 HMM 잠정 RVOL 1.76 → 확정 2.11, 10/7 씨젠은
  잠정에서 탈락했다가 확정 1.51로 통과(A∩B). **전향 기록은 확정 뒤 다시 돌린 결과로 남긴다**
- DART 네트워크 오류(연결·SSL 시간 초과)는 3회까지 다시 시도하고, 100개 묶음이 HTML 오류
  페이지를 받으면 묶음을 나눠 다시 묻는다. 그래도 실패하면 "A 실패" 경고와 함께 A가 빈다
  — 그 스냅샷은 지우고 다시 돌린다
- `--allow-extended`(인자 `extended`)는 정규장 봉이 없는 날을 EXTENDED로 채운다 —
  기준 밖이며 "RVOL 최근 창에 애프터마켓 포함 일봉" 경고로 표시된다
- 복원 봉은 **시가·고가·저가·종가가 KRX 공식 일별매매정보와 3,148/3,148 일치**한다
  (KRX 공식 종가 = 정규장 종가). 거래량은 KRX 공식값(애프터마켓 포함)에서 애프터마켓
  분봉 거래량을 뺀 값이라 공식값과 다르다. 거래대금은 공식값 × 정규장 거래량 비율(추정)
- 주말·연휴 뒤에는 "일봉 최신일이 N일 전" 경고가 정상이다(예: 2026 추석 9/24~26 → 기준일 9/23)
- 유니버스 이력 마지막 관측일 이후 날짜는 가장 가까운 관측 구성으로 대체된다(경고 표시)

## B 정의 (바꾸면 다른 설계입니다)

```
RVOL      = mean(거래량, D-4 … D) / mean(거래량, D-54 … D-5)     # 1주 vs 이전 50일
52주 근접 = 종가_D / max(고가, 최근 252거래일)                     # 1.0이면 신고가
```

게이트

1. 최근 252거래일 중 **240일 이상** 일봉 존재(52주 고가를 정의할 수 있어야)
2. **RVOL ≥ 1.5**
3. **52주 근접 ≥ 0.90** (고가 대비 -10% 이내)
4. 20일 평균 거래대금 **≥ 10억 원**

점수(100) = RVOL 백분위 × 50 + 52주 근접 백분위 × 50 (그날 유니버스 내)

백테스트는 여기에 **재신호 억제**(같은 종목은 직전 신호 후 20거래일 안의 재통과를
세지 않음)와 **다음 거래일 시가 진입**을 적용했습니다.

## A 정의

```
분기 단독 영업이익: 1~3Q는 thstrm_amount(3개월),
                    4Q = 사업보고서 연간 − 3Q 누적
ΔQ_t   = Q_t − Q_{t-4}          전년 동기는 같은 보고서의 frmtrm 사용
SUE_t  = ΔQ_t / 표준편차(ΔQ_{t-1} … ΔQ_{t-8})     최소 4개 필요
이벤트일 = 잠정실적 공시일(영업(잠정)실적) — 없으면 정기보고서 접수일
```

게이트: SUE 계산 가능 · **SUE ≥ 1.0** · 이벤트 후 경과 ≤ 60거래일 · 20일 평균
거래대금 ≥ 10억. 정렬은 SUE 내림차순.

> ⚠ **실거래 제약**: SUE는 정기보고서의 **확정** 영업이익으로 계산합니다(잠정치를
> 구조적으로 받을 API가 없음). 따라서 후보는 정기보고서가 접수된 **뒤에야**
> 목록에 나옵니다 — A2 백테스트의 진입보다 늦습니다. **A2 수익률을 이 목록의
> 기대수익으로 읽으면 안 됩니다.**

## A∩B 표시

B 통과 종목에 "신호일에 이미 접수된 가장 최근 분기 SUE ≥ 1.0 & 그 보고서 접수 후
60거래일 이내"면 **A 조건 충족 표시**가 붙습니다(`ab-draft-0.3`).
**B의 선정 기준은 바뀌지 않았습니다 — 표시만 늘었습니다.**

A∩B가 나머지 B보다 나았다는 결과(q=0.03)는 **탐색**입니다: 가설의 출처와 검정
표본이 같은 16년·같은 SUE 데이터에 있습니다. 게다가 효과가 앞 반기간
(2017-2021 +3.41%p)에 몰리고 뒤 반기간(2022-2026 +1.21%p)은 구간이 0을
포함합니다.
