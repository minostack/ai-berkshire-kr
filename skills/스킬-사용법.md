# AI Berkshire KR — 스킬 사용법 정리

`skills/` 디렉토리에 등록된 전체 스킬의 호출 방법과 용도 요약입니다.
각 `.md` 파일은 `~/.claude/commands/`에 복사되어 `/스킬명` 슬래시 명령으로 실행됩니다.

> **공통 원칙** (CLAUDE.md): 객관성 우선, 사실과 의견 엄격 구분, 양면 제시, 추정값은 "추정" 명시, 리포트는 한국어.
> **데이터 수집**: `Fetch(finance.naver.com / comp.fnguide.com / data.krx.co.kr)` 직접 접속 금지 → `python3 tools/*.py` 또는 `WebSearch` 사용. 자세한 규칙은 `financial-data` 스킬 참조.

## 1. 종목 발굴 / 스크리닝

### `/kr-stock-scanner` — 한국 주식 종목 발굴 스캐너
- **용도**: KOSPI/KOSDAQ에서 정량 필터 → 정성 필터 2단계로 투자 후보 리스트 생성. 숫자만 좋고 사업이 나쁜 종목은 제외.
- **입력 형식**:

  | 입력 유형 | 예시 |
  |-----------|------|
  | 테마/섹터 | `/kr-stock-scanner AI 반도체` · `K-방산` · `바이오` |
  | 시장 전체 | `/kr-stock-scanner KOSPI 대형주` · `KOSDAQ 성장주` |
  | 조건 지정 | `/kr-stock-scanner ROE 15% 이상 저PBR` |
  | 비어 있음 | `/kr-stock-scanner` (기본 4대가 기준 전 섹터 스캔) |
- **데이터**: `python3 tools/kr_scanner.py` + `tools/kstock_data.py` (DART API) → `WebSearch` → DART URL 안내 순.
- **출력**: `reports/{기업명}-checklist-{YYYYMMDD}.md` 형태 아님 — 스캔 결과 리스트. (개별 종목 심층 분석은 아래 연계 스킬로)
- **연계**: 발굴 → `/investment-team` 또는 `/investment-research` 심층 분석.

### `/daily-scanner` — 당일 투자 후보 스캐너 (기술적)
- **용도**: 단기 기술적 신호(모멘텀 돌파·거래량 급증·갭·과매도 반등)로 당일~수주 진입 타이밍 후보 발굴. `kr-stock-scanner`가 중장기 가치라면 이 스킬은 단기 모멘텀.
- **입력 형식**:
  ```
  /daily-scanner                 # 기본 스캔(전체 조건)
  /daily-scanner momentum        # 모멘텀 돌파
  /daily-scanner volume          # 거래량 급증
  /daily-scanner gap             # 갭 상승/하락
  /daily-scanner oversold        # 과매도 반등 후보
  /daily-scanner sector 반도체   # 특정 섹터 기술적 스캔
  /daily-scanner broker 한국투자 # 증권사 API 연동(KIS)
  /daily-scanner broker 키움     # 키움 OpenAPI 연동
  /daily-scanner indicators 009150  # 단일 종목 RSI/MACD/볼린저 확인
  ```
- **사전 확인**: `python3 tools/daily_scanner.py check-market` / `check-broker`
- **데이터**: `python3 tools/daily_scanner.py` — 일봉은 로컬 정규장 일봉(봉 기준 bars-1.0) + 당일 키움 API 봉. 로컬이 비면 키움 API·Yahoo(기준 밖) → `WebSearch`.
- **연계**: `/cvd-obv-scan` → `/daily-scanner indicators` → `/investment-team`.

### `/cvd-obv-scan` — CVD/OBV 기반 당일 후보 스캐너
- **용도**: 키움 REST API 분봉으로 코스피200/코스닥150의 CVD(누적 거래량 델타)와 OBV를 계산해 종합 스코어 상위 종목 출력. 방향성과 다이버전스 판단이 핵심.
- **입력 형식**:
  ```
  /cvd-obv-scan                        # 코스피200 기본(5일, 5분봉, 상위10)
  /cvd-obv-scan kospi200               # 코스피200 상위 10
  /cvd-obv-scan kosdaq150              # 코스닥150 상위 10
  /cvd-obv-scan both                   # 코스피200 + 코스닥150
  /cvd-obv-scan kospi200 --days 10     # 10영업일 CVD (20도 가능)
  /cvd-obv-scan kospi200 --top 20      # 상위 20개
  /cvd-obv-scan kospi200 --period 1    # 1분봉(더 정밀)
  /cvd-obv-scan detail 009150          # 단일 종목 상세 분석
  /cvd-obv-scan update-index           # 종목 목록 최신화
  ```
- **사전 준비**: `.env`에 `KIWOOM_APP_KEY` / `KIWOOM_APP_SECRET` 등록. `python3 tools/update_index.py`로 종목 목록 생성.
- **핵심 도구**: `python3 tools/cvd_obv_scan.py scan --index kospi200 --top 10` — 계산은 동결된 V1.5 그대로, 봉만 기준(bars-1.0)에 맞춰 넣는다(일봉 = 로컬 정규장, 분봉 = 1분봉 합성). `kiwoom_cvd_obv_scanner.py` 직접 실행은 과거 결과 재현용.
- **스코어·판정**: 100점 백분위 점수(CVD 40 + OBV 35 + 가격 15 + 유동성 10 − 과열 5)와 **별개로** Absolute Gate가 🟩후보/🟨관찰/⬜부족을 판정한다.
- **측정된 정보량**: 250거래일 실측에서 D+1~D+20 **어느 지평도 유니버스를 이기지 못했다**(10칸 중 9칸 음수). 유동성·데이터 품질 필터로는 유효 — `docs/CVD-전체정리-20260927.md` 참고.
- **출력**: `reports/daily-scan/cvd-obv-{인덱스}-{YYYYMMDD}.md`
- **주의**: 로컬 일봉이 최신이어야 한다(16:10 `data-load provisional` 잠정 · 익일 08:30 `data-load daily` 확정, 작업 스케줄러 자동). 마감 판단은 15:35~16:00 실행이 가장 정확(당일 정규장 일봉이 붙는다). CVD는 분봉 추정 근사값. 코스피200/코스닥150 정기변경(6·12월) 시 `update_index.py` 재실행.
- **연계**: 상위 후보 → `/daily-scanner indicators` → `/investment-team`.

### `/cvd-accel-scan` — CVD 가속 스캐너 (1분봉)
- **용도**: 일별 CVD 흐름의 **변화율(가속 A = 최근 3일 평균 − 이전 7일 평균)** 로 종목 선정. `/cvd-obv-scan`(V1.5)이 `종가>MA20`·`OBV>MA20` 같은 **수준** 조건 때문에 이미 오른 종목만 뽑던 문제를 겨냥한 별도 설계.
- **입력 형식**:
  ```
  /cvd-accel-scan                      # 코스피200+코스닥150 통합, 1분봉, 상위 15
  /cvd-accel-scan kospi200             # 코스피200만
  /cvd-accel-scan detail 005930        # 단일 종목 — 일별 흐름 10일 막대
  /cvd-accel-scan check                # 앞 3종목만 돌려 연결 확인
  ```
- **핵심 도구**: `python3 tools/cvd_accel_scanner.py scan --index both --top 15 --save-json`
- **게이트(5)**: 연속 10거래일 확보 · **A>0** · **최근 3일 흐름>0** · 유동성 존재 · **MA20 대비 +10% 이내(과열 제외)**. `종가>MA20`·`OBV>MA20`·`매수우위일≥50%`는 **일부러 제외**(회귀 테스트로 고정).
- **배점**: 가속 백분위 60 + 최근흐름 20 + 유동성 20.
- **검증 상태**: **선행성만 확립**(신호 전 상승폭 +20.15%→+0.25%, 상승 비율 97.8%→55.2%). **수익은 미확립** — 거래당 95% 구간이 0을 포함하고, 일봉 대리 15.7년 D→D+2는 -0.162%(구간 0 불포함). **단독 매매 근거로 쓰지 말 것.**
- **실행 시점**: 완료된 정규장만 사용 → **15:35 이후** 실행(확정 종가는 시간외 종가매매 15:40~16:00로 집행 가능). 349종목 약 6분 30초.
- **출력**: `reports/daily-scan/cvd-accel-{인덱스}-{시각}-{실행ID}.json`
- **연계**: `/cvd-obv-scan detail`(수준 지표 대조) → `/investment-team`.

### `/ab-candidate-scan` — A·B 후보 선정기 (학술 근거 지표군)
- **용도**: CVD 계열에서 우위를 못 찾은 뒤 도입한 두 후보. **B** = 거래량 급증(RVOL 5일/50일 ≥ 1.5) + 52주 신고가 근접(≥0.90), 보유 20거래일. **A** = 실적 서프라이즈 후 표류(SUE ≥ 1.0), 보유 20~60거래일.
- **입력 형식**:
  ```
  /ab-candidate-scan                   # A와 B 모두
  /ab-candidate-scan B                 # B만 — 로컬 일봉만, 네트워크 없음
  /ab-candidate-scan A                 # A만 (DART 조회)
  /ab-candidate-scan date 2026-09-22   # 기준일 지정
  /ab-candidate-scan refresh           # DART 캐시 무시(정정보고서 반영)
  ```
- **핵심 도구**: `python3 tools/ab_candidate_scanner.py --mode B`
- **검증 상태**: **B는 유니버스 동일가중 대비 +1.090%**[+0.582, +1.631] q<0.0001로 유의(16년·6,131건). 그러나 **코스피200 지수 대비는 +0.007%로 판정 불가**(UNDERPOWERED). 보유를 40·60일로 늘리면 유니버스 대비 +2.01%·+2.93%. **A는 표본(2016~)이 얇아 판정 불가.** A∩B 표시는 탐색 결과(q=0.03, 앞 반기간에 몰림).
- **사전 준비**: B는 로컬 일봉만. A는 `.env`의 `DART_API_KEY` 필요.
- **출력**: `reports/daily-scan/ab-candidates-*.json`
- **주의**: **지수를 이긴다는 증거가 없다.** A 후보는 정기보고서 접수 뒤에야 목록에 나오므로 A2 백테스트 수익률을 기대수익으로 읽으면 안 된다.
- **연계**: `/earnings-review`(A 후보 1차 자료) → `/investment-team`.

### `/closing-bet-scan` — 종가매수 후보 스캐너 (일봉 패턴)
- **용도**: 코스피200·코스닥150의 최근 1개월 일봉에서 **A**(장대 양봉 후 5일선 위 도지 2~3일) · **B**(장대 양봉 후 4연속 음봉 → 20일선 지지 양봉) · **C**(상한가/장대 양봉 후 8~12봉 기간 조정 → 거래량 동반 5일선 돌파) · **D**(거래대금 동반 5/20/60일 신고가) 후보. A·B·C는 조정 중 거래량 감소 필수.
- **입력 형식**:
  ```
  /closing-bet-scan                    # 로컬 일봉, 최신 거래일
  /closing-bet-scan live               # KIS 당일 봉 + 장중 봉 (15:20 전후 종가매수용)
  /closing-bet-scan kis                # KIS 당일 봉, 완료 봉만(15:35~16:00 실행이 가장 정확)
  /closing-bet-scan date 2026-09-22    # 기준일 지정
  /closing-bet-scan A,C                # 일부 유형만
  /closing-bet-scan d20                # D형 신고가 기준 20일
  /closing-bet-scan noprobe            # 시장 최신 거래일 조회 생략
  ```
- **핵심 도구**: `python tools/closing_bet_scanner.py [--source kiwoom --live] [--allow-extended]`, 백테스트 `python tools/closing_bet_backtest.py`

### `/minute-collect` — 분봉 일일 누적 (비어 있는 것만)
- **용도**: 저장소에 **비어 있는 1분봉만** 찾아 수집. "어제"가 아니라 커버리지와 API 응답을 대조하므로 **하루 이틀 늦게, 연휴 뒤에 돌려도 빠진 날이 모두** 채워진다. 같은 날 두 번 돌리면 두 번째는 받을 것이 없다(멱등).

- **핵심 도구**: `python cvdobv.py minute-cache catchup --period 1 --days 10`
- **일일 적재는 `data-load daily`가 대신한다**: 1분봉 → 일봉 → 정규장 복원을 한 번에(봉 기준 bars-1.0, `docs/BAR_STANDARD.md`). 이 스킬은 분봉만 따로 채울 때 쓴다.
- **자동 실행**(2026-10-06 등록): "CVD 잠정 일봉 적재" 월~금 16:10(`scripts/provisional-load.bat`, 로그 `logs/provisional-load/`) · "CVD 정규장 확정 적재" 월~토 08:30(`scripts/daily-load.bat`, 로그 `logs/daily-load/`). 둘 다 마지막 확정일 이후 밀린 날을 먼저 확정한다.
- **판정**: 목표 거래일은 **저장된 캘린더가 아니라 API 응답**에서 얻는다(캘린더는 수집한 일봉에서 파생돼 뒤처진다 — 실측 2026-09-27에 캘린더 09-22 / 실제 09-23). 끝나지 않은 세션은 목표에서 제외. 봉 수가 기대치의 80% 미만이면 다시 받는다.

## 5. 보유 후 관리 / 추적

### `/thesis-tracker` — 투자 논거 추적 (中文 스킬)
- **용도**: 매수 전에 매도 조건까지 써두고 분기마다 논거 완결성 점검. "연구 → 매수 → 기도"의 빈틈을 메움.
- **입력 형식**:
  ```
  /thesis-tracker 공司名           # 최초: 논문 수립 / 이후: 추적 점검
  /thesis-tracker 공司名 建立论文   # 강제 재수립
  /thesis-tracker 공司名 季度检查   # 최신 재보 기준 점검
  ```
- **모드**: 파일(`reports/{기업명}-thesis.md`) 존재 여부로 수립/추적 자동 판단.
- **도구**: `tools/financial_rigor.py verify-valuation`로 밸류에이션 검증.
- **출력**: `reports/{기업명}/{기업명}-thesis.md` (장기 유지·지속 업데이트).

### `/thesis-drift` — 논거 변화 추적 (두 시점 비교)
- **용도**: 두 시점 리포트를 나란히 비교해 논거 침식(Thesis Drift)의 방향·속도를 정량화. `thesis-tracker`가 단일 파일 시간축 추적이라면 이 스킬은 두 시점 대조.
- **입력 형식**:
  ```
  /thesis-drift 삼성전기 reports/삼성전기-thesis-2025Q2.md reports/삼성전기-thesis-2025Q4.md
  /thesis-drift 카카오 reports/카카오-research-20250601.md reports/카카오-research-20251201.md
  ```
  - 첫 번째 = 이전(구 논거), 두 번째 = 최근(신 논거). 파일 1개만 주면 최근 2개 리포트를 자동 탐색.
- **데이터**: 입력된 로컬 리포트 파일 직접 읽기(우선) → `WebSearch`로 최신 상황 보완.

### `/portfolio-review` — 조합 관리 (中文 스킬)
- **용도**: 개별 종목이 아닌 포트폴리오 전체 관점 — 비중, 자금 출처(신규 자금 vs 교체), 기존 보유와의 상관성, 기회비용("이게 내가 할 수 있는 최선인가?").
- **입력 형식**:
  ```
  /portfolio-review 腾讯30%, 美团20%, 茅台20%, 英伟达15%, 现金15%
  /portfolio-review 腾讯 500股 @480港元, 美团 1000股 @130港元, ...
  /portfolio-review 我的持仓        # 저장된 reports/portfolio-latest.md 사용
  ```
- **출력**: `reports/portfolio-latest.md` (루트, 지속 업데이트). `.gitignore` 대상 — 실제 포지션 비공개.

### `/news-pulse` — 공사 뉴스 맥박 (中文 스킬)
- **용도**: 보유/관심 종목 주가가 크게 움직였을 때(단일일 ±5%, 1주 ±10% 등) 10분 내 "무슨 일이 있었나 / 이상 급등락의 진짜 원인 / 논거 재심 필요 여부"를 4개 병렬 에이전트(공사 이벤트·감독 정책·행업 경쟁사·시장 정서)로 규명. 심층 투research 아님.
- **입력 파라미터**: 공사명(필수) / 시간 창(기본 14일, 재보철 7일) / 주가 이상(예 "跌 12%/3天") / 관심 측면(공사·감독·행업·정서).
- **부적합**: 완전 투research(→ `/investment-team`), 재보 심독(→ `/earnings-review`), 장기 논거 추적(→ `/thesis-tracker`).

### `/management-deep-dive` — 경영진 종적 심층 조사 (中文 스킬)
- **용도**: `/investment-research` 5단계(경영진 평가)의 심화판. 경영진 점수가 불확실(★★★ 이하)하거나 경영진이 핵심 투자 논리일 때 사용. 언행일치(약속 vs 이행), 자본배분 결정별 회수율, 곤경기 결정에서 품격 추론, 직원·고객 피드백 측면 검증.
- **입력 형식**: `公司名` 또는 `人名 公司名` — `/management-deep-dive 美团` · `/management-deep-dive 王兴 美团` · `/management-deep-dive 黄仁勋 英伟达`.
- **절차**: WebSearch로 핵심 인물 확인 → Task 병렬 에이전트로 공개 발언·예측 기록 등 수집.

## 6. 인컴 투자

### `/income-investment` — 인컴 투자 분석 (배당·이자)
- **용도**: 배당수익률이 아니라 배당 지속가능성·성장성 중심 분석. 고배당이 저평가 우량주인지 배당 컷 함정 종목인지 구분.
- **입력 형식** (key=value):
  ```
  /income-investment 삼성전자 mode=new role=core-income quantity=100 cost_basis=78000 tax_residence=KR horizon=5y
  /income-investment KT mode=existing role=satellite quantity=200 cost_basis=35000 tax_residence=KR horizon=3y
  /income-investment SCHD mode=new role=core-income quantity=50 cost_basis=27.50 tax_residence=KR horizon=10y
  ```

  | 파라미터 | 값 |
  |----------|-----|
  | `mode` | `new`(신규 매수 검토) / `existing`(기존 보유 검토) |
  | `role` | `core-income` / `satellite` / `growth-income` |
  | `quantity` | 보유(예정) 수량 |
  | `cost_basis` | 매수 단가(원 또는 달러) |
  | `tax_residence` | `KR` / `US` / `JP` … (원천징수 계산용) |
  | `horizon` | `3y` / `5y` / `10y` … |
- **데이터**: `python3 tools/kstock_data.py quote {종목코드}` → `WebSearch`(배당 이력·성향·성장률) → DART URL.
