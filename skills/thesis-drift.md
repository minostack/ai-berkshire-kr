# 투자 논거 변화 추적: 두 시점 비교 분석

$ARGUMENTS 에 대해 두 시점의 투자 리포트를 비교하여 투자 논거가 어떻게 변화했는지 분석합니다.

**지원 입력 형식**:

```
/thesis-drift 삼성전기 reports/삼성전기-thesis-2025Q2.md reports/삼성전기-thesis-2025Q4.md
/thesis-drift 카카오 reports/카카오-research-20250601.md reports/카카오-research-20251201.md
```

- **첫 번째 파일**: 이전 시점 리포트 (구 논거)
- **두 번째 파일**: 최근 시점 리포트 (신 논거)
- 파일이 하나만 입력되면 가장 최근 두 개의 리포트를 자동으로 찾아서 비교

---

## 설계 철학

> "투자에서 가장 위험한 말은 '이번엔 다르다'이다." — 존 템플턴
>
> "매수 이유가 사라졌다면 팔아야 한다. 주가가 올랐기 때문이 아니라." — 버핏

이 스킬은 **투자 논거의 침식(Thesis Drift)**을 조기에 발견하는 것이 목적입니다.

투자 논거 침식이란 처음 매수할 때의 핵심 근거가 시간이 지나면서 조용히 훼손되는 현상입니다. 주가가 오르거나 별다른 나쁜 뉴스가 없어서 알아채기 어렵지만, 어느 순간 돌아보면 "내가 왜 이 주식을 샀더라?"가 되어 있습니다.

**thesis-tracker와의 차이**:
- `/thesis-tracker`: 하나의 리포트를 시간 축으로 지속 업데이트 (단일 파일 추적)
- `/thesis-drift`: **두 시점의 리포트를 나란히 비교** (변화의 방향과 속도 정량화)

---

## ⚠️ 데이터 수집 필수 규칙

```
방법 1 (우선): 입력된 로컬 리포트 파일 직접 읽기 (Bash로 파일 접근)
방법 2 (보완): WebSearch — 최신 기업 상황 확인
방법 3 (최후): DART URL 안내
❌ 금지: Fetch(finance.naver.com/...) 직접 접속
```

## 실행 흐름

### 0단계: 파일 확인 및 로드

```bash
# 입력된 두 리포트 파일 존재 확인
ls -la {파일1} {파일2}

# 파일 크기 및 수정 날짜 확인
stat {파일1} {파일2}
```

파일이 없거나 하나만 입력된 경우:
```bash
# reports/ 폴더에서 해당 종목 리포트 자동 탐색
ls -lt reports/{종목명}/ | head -10
```

가장 오래된 것과 가장 최신 것을 자동 선택하거나 사용자에게 선택지를 제시합니다.

### 1단계: 양쪽 리포트 핵심 요소 추출

두 리포트에서 아래 5가지 핵심 요소를 각각 추출합니다:

#### 추출 대상

| 요소 | 설명 |
|------|------|
| **최종 판정** | 매수 / 관망 / 회피 또는 점수 |
| **핵심 매수 논거** | 왜 이 종목인가 (3~5가지) |
| **핵심 리스크** | 무엇이 틀릴 수 있는가 (3~5가지) |
| **밸류에이션 기준** | 적정가치 / 목표주가 / 안전마진 |
| **핵심 가정** | 논거의 기반이 되는 전제 조건들 |

---

### 2단계: 변화 유형 분류

각 요소의 변화를 아래 4가지 유형으로 분류합니다:

| 유형 | 기호 | 의미 |
|------|------|------|
| 강화 | 🟢 ↑ | 논거가 더 확실해짐 |
| 유지 | ⬜ → | 큰 변화 없음 |
| 약화 | 🟡 ↓ | 논거가 불확실해짐 |
| 훼손 | 🔴 ✕ | 핵심 가정이 깨짐 |

**훼손 신호 특별 주의**:
처음 매수 시 "이것만 지켜지면 된다"고 적었던 핵심 가정이 깨진 경우 자동으로 🚨 경고를 표시합니다.

### 4단계: 논거 강도 점수 변화

각 리포트의 논거 강도를 정량화해서 비교합니다.

**채점 방식**:
- 매수 논거 강화: +2점
- 매수 논거 유지: 0점
- 매수 논거 약화: -1점
- 핵심 가정 훼손: -3점
- 새로운 긍정 촉매 발견: +2점
- 새로운 리스크 발생: -2점

```
논거 강도 변화 = Σ(변화 점수)

> 0: 논거 강화 — 포지션 유지 또는 증액 근거
= 0: 논거 중립 — 현상 유지
< 0: 논거 약화 — 원인 파악 및 재검토 필요
< -5: 논거 훼손 — 매도 검토 즉시 시작
```

---

### 5단계: 외부 환경 변화 대조

두 리포트 작성 시점 사이에 어떤 외부 변화가 있었는지 WebSearch로 확인합니다.

```
WebSearch: "{종목명} {이전날짜}~{최신날짜} 주요 이벤트"
WebSearch: "{종목명} 실적 변화 {기간}"
WebSearch: "{종목명} 업계 경쟁 변화 {기간}"
```

**확인 항목**:
```
□ 경쟁사 동향 변화 (신규 진입자, 경쟁 심화/완화)
□ 실적 발표 결과 (예상 대비 초과/미달)
□ 경영진 변화 (CEO 교체, 임원 이탈)
□ 규제·정책 변화
□ 산업 구조 변화 (기술 혁신, 수요 패턴)
□ 거시 환경 변화 (금리, 환율, 경기)
```

### 6단계: 행동 지침 도출

논거 변화 분석을 기반으로 구체적인 행동 지침을 제시합니다.

| 논거 강도 변화 | 권장 행동 | 우선 확인 사항 |
|-------------|---------|-------------|
| +5 이상 | 🟢 증액 검토 | 밸류에이션이 여전히 매력적인지 |
| +1 ~ +4 | 🟢 유지 | 다음 실적 발표 주시 |
| -1 ~ 0 | ⬜ 현상 유지 | 약화 요소 모니터링 강화 |
| -2 ~ -4 | 🟡 주의 | 핵심 가정 재점검 필요 |
| -5 이하 | 🔴 매도 검토 즉시 | 손실 규모보다 논거 훼손이 더 중요 |
| 핵심 가정 훼손 | 🚨 즉각 검토 | 논거 점수와 무관하게 즉시 재검토 |

## 주요 주의사항

1. **손실 회피 편향 주의**: 논거가 훼손됐는데 손실이 나서 못 파는 것은 잘못된 판단입니다. 논거가 사라졌다면 손실 여부와 무관하게 매도를 검토해야 합니다
2. **확증 편향 주의**: 두 리포트를 비교할 때 자신이 원하는 결론에 유리한 변화만 보려는 경향을 의식적으로 경계합니다
3. **이 분석은 투자 권유가 아닙니다** — 최종 판단은 본인의 책임입니다
4. **리포트 파일이 없으면**: `/investment-research` 또는 `/investment-team`으로 먼저 리포트를 생성하세요
