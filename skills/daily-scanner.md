# 당일 투자 후보 스캐너: 기술적 분석 + 전일 특이 종목

당일 또는 전일 시장 데이터를 기반으로 기술적 조건을 충족하는 투자 후보 종목을 발굴합니다.

**지원 입력 형식**:

```
/daily-scanner                          # 기본 스캔 (전체 조건)
/daily-scanner momentum                 # 모멘텀 돌파 종목
/daily-scanner volume                   # 거래량 급증 종목
/daily-scanner gap                      # 갭 상승/하락 종목
/daily-scanner oversold                 # 과매도 반등 후보
/daily-scanner sector 반도체            # 특정 섹터 기술적 스캔
/daily-scanner broker 한국투자          # 증권사 API 연동 (KIS — 데이터 원천)
```

---

## 설계 철학

> "차트는 시장 참여자들의 심리가 응축된 것이다. 패턴이 반복되는 이유는 사람의 탐욕과 공포가 반복되기 때문이다."

이 스킬은 **단기 기술적 신호**를 포착해서 당일 또는 단기 투자 후보를 발굴합니다.
`/kr-stock-scanner`가 중장기 가치 기반 스크리닝이라면, 이 스킬은 **단기 모멘텀과 가격 패턴** 기반입니다.

**두 스킬의 역할 분리**:

| 스킬 | 기준 | 시간 지평 | 용도 |
|------|------|---------|------|
| `/kr-stock-scanner` | 재무·가치 | 중장기 (1년+) | 종목 발굴 |
| `/daily-scanner` | 기술적·모멘텀 | 단기 (당일~수주) | 진입 타이밍 |

두 스킬을 함께 사용하면 **가치 있는 종목의 좋은 타이밍**을 잡을 수 있습니다.

### 1단계: 전일 특이 종목 수집

전일 마감 기준 아래 조건으로 특이 종목을 수집합니다:

#### 1-1. 거래량 급증 종목

```bash
python3 tools/daily_scanner.py volume-surge \
  --ratio 3.0 \
  --min-cap 500 \
  --market all   # all/kospi/kosdaq
```

기준(가이드 7.1 정확한 공식 구현):
- `ratio = 오늘 거래량 / (직전 20완료봉 평균 거래량)` ≥ 3.0
- 시가총액 500억 이상 (소형주 노이즈 제거)
- KIS 거래량순위(FHPST01710000, 거래증가율 = 전일 대비, ETF·ETN·스팩 제외)를 코스피·코스닥 각 30종목씩 후보 풀로 받아 종목별 일봉 재조회로 위 공식을 정확히 재계산함(coverage=rank_subset — 전체 시장이 아닌 상위 후보 한정)
- 후보의 로컬 일봉이 없거나 끊겼으면(지수 밖·편출 종목) KIS 일봉(기준 밖)으로 계산하고 그 개수를 표시함
- 장중 실행 시 당일 거래량은 미완료(누적 중) 수치이며 결과에 🕐로 표시됨

#### 1-2. 신고가 돌파 종목

```bash
python3 tools/daily_scanner.py new-high \
  --period 52w \
  --market all   # all/kospi/kosdaq
```

기준(로컬 기준 일봉으로 직접 판정 — coverage=index_kospi200_kosdaq150, 전체 시장 아님):
- 종가 기준 확정 돌파: `종가 > 직전 N거래일 중 최고가` (오늘 고가는 기준에서 제외, 동일가는 돌파 아님), 완료 봉만 사용
- KIS에는 종가 기준 N일 신고가 순위 TR이 없음(FHPST01870000은 '근접' 순위라 정의가 다름) — 그래서 지수 구성종목만 봄
- `--period`는 5d/10d/20d/60d/120d/250d/52w(=250거래일)
- 거래량 동반 조건은 구현되어 있지 않음(표시되는 20일 평균 대비 거래량 배수는 참고용)

#### 1-3. 갭 상승 종목 (전일 종가 대비)

```bash
python3 tools/daily_scanner.py gap-up \
  --min-gap 3.0 \
  --market all   # all/kospi/kosdaq
```

기준(가이드 7.3 정확한 공식 구현):
- `gap_pct = (오늘 시가 / 전일 종가 - 1) × 100` ≥ 3.0
- 시장 전체 갭 랭킹에 해당하는 KIS TR이 없어 코스피200+코스닥150 유니버스를 종목별로 KIS 현재가(FHKST01010100) 조회함 — coverage=index_kospi200_kosdaq150(전체 시장 아님), 종목 수에 비례해 수십 초 소요
- 갭 유지 여부(시가=고점 근처)는 판정하지 않음

#### 1-4. 과매도 반등 후보

```bash
python3 tools/daily_scanner.py oversold \
  --rsi-max 30 \
  --days 5
```

기준(가이드 7.4 정확한 공식 구현, `data/watchlist.json`의 6자리 국내 종목 전체 대상 — 30개 제한 없음):
- RSI(14, Wilder) ≤ 30
- `days`일 연속 하락(보합 포함 시 하락으로 보지 않음, 기본 5일)
- 볼린저 밴드 하단 터치 조건은 구현되어 있지 않음

### 2단계: 기술적 지표 분석

1단계에서 수집한 후보 종목에 대해 핵심 기술적 지표를 계산합니다.

```bash
python3 tools/daily_scanner.py indicators 005930 000660 035720
```

한 번에 모든 지표(RSI·MACD·볼린저밴드·이동평균·스토캐스틱·OBV·추정 매수/매도 압력·캔들 패턴)를 계산합니다. `--indicators` 옵션으로 선별 계산하는 기능은 없습니다.

#### 계산 지표 목록

| 지표 | 파라미터 | 매수 신호 조건 |
|------|---------|------------|
| **RSI** | 14일, Wilder | 30 이하 (과매도) 후 반등 / 50 상향 돌파 |
| **MACD** | 12,26,9 | 골든크로스 (MACD > Signal) |
| **볼린저밴드** | 20일, 2σ | 하단 터치 후 중심선 회복 / 상단 돌파 |
| **이동평균** | 5/20/60/120일 | 정배열 (5>20>60>120, 데이터 부족 시 "판정 불가"로 별도 표시) |
| **Slow 스토캐스틱** | 14,3,3 (FastK→SlowK→SlowD 3단계 평활) | %K가 %D 상향 돌파, 20 이하에서 |
| **OBV** | — | OBV 상승 + 주가 횡보 (매집 신호) |
| **추정 매수/매도 압력** | 일봉 근사 | 압력 상승 + 가격 하락 다이버전스 (실제 체결 기반 CVD 아님) |
| **거래량 이평** | 20일 | 당일 거래량 > 20일 평균 × 2 |

장중 실행 시 당일(미완료) 봉은 지표 계산에서 제외되고, 실시간가는 별도로 표시됩니다.

### 2-1단계: 100점 스코어링 (선택)

기술적 지표를 개별로 보는 대신 하나의 점수로 요약하고 싶을 때 사용합니다.

```bash
python3 tools/daily_scanner.py score 005930
```

Trend/Momentum/Volume·Liquidity/Foreign·Institution/Pattern·Breakout/Risk 6개
영역, 100점 고정 배점(**검증 전 초기 가설 모델 — 매수 지시 아님**). 필요한
원본 데이터(예: MA120, 외국인·기관 5일 수급)가 없으면 총점을 0점이나
100점 환산으로 채우지 않고 `INCOMPLETE`로 표시하며 결측 항목을 그대로
보여줍니다. 관리종목·ETF 여부를 확인할 공식 API 필드는 아직 찾지 못해
1차 필터에 반영되어 있지 않습니다(가격·시가총액·거래대금만 필터링 — 거래대금은 KIS 누적 거래대금, 없으면 가격×거래량 추정). 주말에는 외국인·기관 수급을 최근 5완료거래일로 계산합니다.

### 3단계: 패턴 인식

```bash
python3 tools/daily_scanner.py patterns \
  --tickers 005930 000660 \
  --patterns all
```

#### 인식 패턴

**강세 패턴** (매수 신호):
- 망치형 (Hammer): 긴 아래꼬리 + 작은 몸통
- 상승 장악형 (Bullish Engulfing): 전일 음봉을 완전히 감싸는 양봉
- 샛별형 (Morning Star): 3일 패턴, 바닥 반전
- 컵앤핸들 (Cup & Handle): 중장기 돌파 패턴

**중립/주의 패턴** (추가 확인 필요):
- 도지 (Doji): 시가 ≈ 종가, 방향 불확실
- 팽이형 (Spinning Top): 작은 몸통, 긴 윗꼬리+아래꼬리

**약세 패턴** (매수 보류):
- 교수형 (Hanging Man): 고점에서의 망치형 → 하락 전환 신호
- 저녁별형 (Evening Star): 고점 3일 패턴, 하락 전환

### 4단계: 증권사 API 연동 (KIS — 2026-11-01 키움에서 전환)

DART나 Yahoo Finance보다 **실시간·정확한** 데이터가 필요할 때 사용합니다.
KIS REST API가 데이터 원천이며(적재 `data-load`와 같은 원천), 모든 명령이 KIS를
씁니다. 키움 키는 이 도구에서 쓰지 않습니다.

```bash
# .env 파일에 키 설정 (최초 1회, .env.example 참고)
#   KIS_APP_KEY=발급받은앱키
#   KIS_APP_SECRET=발급받은시크릿

# 연결 테스트 (인증 + 시세 조회 확인)
python3 tools/daily_scanner.py check-broker

# KIS로 현재가·수급 조회
python3 tools/daily_scanner.py quote 005930 000660 009150

# 거래량 급증 / 신고가
python3 tools/daily_scanner.py volume-surge --market kospi
python3 tools/daily_scanner.py new-high --period 20d --market kosdaq
```

명령별 KIS TR:
```
현재가·시가총액·거래대금 (FHKST01010100)   → quote / indicators / gap-up / score / volume-surge 시총 필터
일봉 (FHKST03010100, 로컬에 없을 때만)      → indicators / oversold / volume-surge / 당일 봉
외국인·기관 순매수 30일 (FHKST01010900)     → quote / score(5일 합, 한 번 호출)
거래량 급증 후보 풀 (FHPST01710000)         → volume-surge
종목명 (CTPF1002R, 지수 밖 종목만)          → 이름 표시
신고가                                      → KIS 순위 없음 — 로컬 기준 일봉으로 직접 계산
```

KIS 일봉은 2026-09-14 이후 거래량이 애프터마켓까지 포함이고, 최근 거래일 가격은 다음 영업일 아침 전까지 애프터마켓 최종가라(`docs/KIS-일봉-최근일-애프터마켓가격-20261101.md`)
봉 기준(bars-1.0) 밖입니다 — 로컬 일봉이 없을 때만 쓰이고 출력에 출처가 표시됩니다.

### 5단계: WebSearch로 뉴스·이슈 교차 확인

기술적 신호가 있는 종목에 대해 당일 뉴스를 확인합니다.

```
WebSearch: "{종목명} 오늘 뉴스 {날짜}"
WebSearch: "{종목명} 공시 오늘"
WebSearch: "오늘 상한가 종목 이유 {날짜}"
WebSearch: "전일 거래량 급증 종목 {날짜}"
```

**뉴스 기반 필터**:
- 호재 뉴스 + 기술적 신호 = 강한 매수 후보
- 악재 뉴스 + 거래량 급증 = 제외 (세력 매도 가능성)
- 뉴스 없음 + 거래량 급증 = 세력 매집 가능성 → 추가 관찰

## 주요 주의사항

1. **기술적 분석은 확률이지 확실성이 아닙니다** — 신호가 맞을 확률을 높이는 것이 목적
2. **단기 스캔 결과로 장기 투자 결정 금지** — 당일 신호는 당일 또는 단기 판단에만 활용
3. **뉴스 없는 거래량 급증 주의** — 세력 매집일 수도 있지만 작전주일 수도 있음
4. **증권사 API 사용 시 모의투자 계좌로 먼저 테스트** 권장
5. **이 스캔 결과는 투자 권유가 아닙니다** — 최종 판단은 본인 책임
6. **심층 분석 필수**: 당일 스캔 후보는 반드시 `/investment-team`으로 검증 후 투자 결정
