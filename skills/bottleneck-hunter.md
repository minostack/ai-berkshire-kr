# 공급망 병목 사냥꾼: AI 기반 글로벌 밸류체인 병목 차익 기회 발굴

$ARGUMENTS 슈퍼 트렌드에 대해 공급망 병목 스캔과 차익 기회 발굴을 수행합니다. 탐색 범위는 글로벌 공급망이고, 최종 후보는 **한국 상장사(KOSPI/KOSDAQ)를 우선**으로 정리합니다.

## 핵심 철학

"AI가 어떤 주식을 추천하나?"를 묻지 않고, "이 트렌드가 계속 확장되면 어느 고리가 먼저 모자라게 되나?"를 묻습니다.

전통적 리서치는 대장주와 이미 알려진 테마를 쫓습니다. 이 시스템은 반대로 갑니다: **물리적 공급망의 목 지점에서 출발해, 아무도 주목하지 않지만 공급이 끊기면 산업 전체가 멈춰 기다려야 하는 회사를 찾습니다**.

초과수익의 원천: 1차 병목(GPU, HBM, 전력)은 이미 충분히 가격에 반영되어 있습니다. 진짜 알파는 **2차·3차 병목**에 있습니다 — 광모듈, 레이저, InP 기판, SOI 웨이퍼, 에피 장비, 웨이퍼 레벨 테스트, IC 기판(패키지 기판), 특수 유리섬유, 후공정 본딩 장비, 전력기기 부품 등.

## 1단계: 슈퍼 트렌드 확인

### 1.1 트렌드 선별 기준

작은 테마에서 환상을 찾지 않고, 다음 조건을 모두 충족하는 슈퍼 트렌드만 추적합니다:

| 기준 | 요건 | 검증 방법 |
|------|------|---------|
| 지속성 | 최소 3~5년의 확실한 성장 | 산업 전망, 설비투자(CAPEX) 계획 검색 |
| 물리성 | 실제 하드웨어/소재/장비 구축 필요 | "소프트웨어 업그레이드"와 "물리적 증설" 구분 |
| 규모 | 글로벌 CAPEX 연 500억 달러 이상 | 주요 업체 CAPEX 가이던스 검색 |
| 가속성 | 수요 증가 속도 > 공급 증설 속도 | 수요 증가율 vs 생산능력 확장 계획 비교 |

### 1.2 현재 추적 중인 슈퍼 트렌드 목록

실행할 때마다 갱신, 초기 목록 (괄호는 한국 상장사와 연결되는 밸류체인 영역):

1. **AI 인프라 구축** — 데이터센터, GPU 클러스터, 네트워크, 전력 (메모리·HBM 후공정 장비, 패키지 기판·MLB, 전력기기)
2. **에너지 전환** — 원전 재가동·신규 건설, 전력망 업그레이드, ESS (원전 기자재, 변압기·차단기, 전선·케이블)
3. **국방 현대화** — 서방 국방비 확대 사이클, 공급망 재편 (방산 체계·부품, 탄약·화약)
4. **반도체 재산업화** — 미·유럽·일본 보조금 공장 건설, 장비/소재 병목 (반도체 장비·소재·부품)
5. **우주 경제** — 위성 인터넷, 발사 빈도 급증 (위성 부품, 발사체 부품)

사용자가 특정 트렌드(예: "AI 인프라")를 지정하면 해당 트렌드에만 집중합니다. 목록에 없는 트렌드(예: 조선·LNG 운반선 교체 사이클)도 1.1 기준을 모두 통과하면 추가할 수 있습니다.

## 2단계: 공급망 물리적 분해

### 2.1 계층 분해 프레임워크

**개념 수준에 머물지 않고 물리적 실체까지 분해합니다**.

```
Layer 0 (최종): 최종 제품/서비스
    │
Layer 1 (핵심 부품): 시장이 이미 충분히 주목하는 핵심 하드웨어
    │                 ⬆ 가격 반영 충분, 알파 제한적
    │─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
    │                 ⬇ 관심도 낮음, 알파 집중 구간
    │
Layer 2 (하위 부품/소재): 핵심 부품을 받치는 부품과 소재
    │
Layer 3 (상류 장비/원료): 하위 부품 제조에 필요한 장비와 원자재
    │
Layer 4 (기반 인프라): 전력, 냉각, 부지, 인력, 인증
```

### 2.2 AI 인프라 분해 템플릿 (예시)

```
Layer 0: AI 모델 학습/추론 서비스
Layer 1: GPU/가속기, HBM 메모리, 서버, 데이터센터
Layer 2 (중점 스캔 구간):
  ├─ 네트워크: 광모듈, 광섬유, 스위치 칩, 구리 케이블
  ├─ 광통신 핵심: 레이저(EML/VCSEL/CW), 변조기, 광검출기
  ├─ 반도체 소재: InP 기판, GaAs 기판, SOI 웨이퍼, SiC 기판
  ├─ 첨단 패키징: CoWoS 기판, HBM TSV·TC 본딩, ABF 필름, 하이브리드 본딩
  ├─ PCB/기판: 고다층 MLB, 고주파·고속 PCB, IC 기판(FC-BGA), 특수 유리섬유 직물
  ├─ 테스트: 웨이퍼 레벨 테스트(프로브카드), 번인 테스트, ATE, 테스트 소켓
  ├─ 방열/냉각: 액체냉각 시스템, CDU, 액침 냉각액
  └─ 전력 연결: 버스덕트, UPS, 배전반, 변압기
Layer 3:
  ├─ 에피 장비: MOCVD, MBE
  ├─ 노광/식각: 특수 파장 노광, InP 식각
  ├─ 원자재: 고순도 금속(인듐, 갈륨, 게르마늄), 특수가스, 타깃재
  └─ 인증/표준: MSA 표준, Telcordia 인증
Layer 4:
  ├─ 전력: 원전, 가스발전, 송변전
  ├─ 냉각수/방열 인프라
  └─ 데이터센터 부지/인허가
```

확인된 슈퍼 트렌드마다 같은 방식으로 분해합니다. WebSearch로 영문·한글 모두 검색:

## 3단계: 병목 식별 — "목 지점" 찾기

### 3.1 병목 판정 6개 기준

Layer 2~3의 각 고리를 항목별로 평가합니다:

| # | 기준 | 질문 | 점수 |
|---|------|------|------|
| 1 | **공급 집중도** | 글로벌 공급사 3곳 이하? | 🔴 2곳 이하 / 🟡 3~5곳 / 🟢 5곳 초과 |
| 2 | **증설 기간** | 신규 생산능력 확보에 얼마나 걸리나? | 🔴 2년 초과 / 🟡 1~2년 / 🟢 1년 미만 |
| 3 | **대체 난이도** | 다른 기술/소재로 대체 가능한가? | 🔴 대체 불가 / 🟡 일부 대체 / 🟢 쉽게 대체 |
| 4 | **가동률** | 현재 생산능력 가동률? | 🔴 90% 초과 / 🟡 70~90% / 🟢 70% 미만 |
| 5 | **수요 증가율** | 하류 수요 증가율? | 🔴 연 50% 초과 / 🟡 20~50% / 🟢 20% 미만 |
| 6 | **고객 인증 기간** | 신규 공급사 진입에 필요한 검증 기간? | 🔴 1년 초과 / 🟡 6~12개월 / 🟢 6개월 미만 |

**병목 등급**:
- 🔴 4개 이상 → **S급 병목** (단일 장애점 수준, 최우선)
- 🔴 3개 → **A급 병목** (심각한 제약)
- 🔴 1~2개 → **B급 병목** (압박 있으나 통제 가능)
- 🔴 없음 → 병목 아님, 건너뜀

```
  2.
```

## 4단계: 기업 선별 — 병목에서 종목으로

### 4.1 S급·A급 병목마다 관련 상장사 전부 찾기

검색 방식:
- WebSearch "{병목 고리} supplier listed company" / "{병목 고리} manufacturer stock"
- WebSearch "{병목 제품} market share company"
- WebSearch "{병목 고리} 국내 상장사", "{병목 제품} 점유율 국내 업체", "{병목 제품} 국산화"
- 한국 상장사는 `python3 tools/kstock_data.py search {기업명}`으로 종목코드 확인

### 4.2 1차 선별 기준 (빠른 필터)

| 기준 | 요건 | 이유 |
|------|------|------|
| 상장 여부 | 상장사 — **KOSPI/KOSDAQ 우선**, 해외(미/일/대만/홍콩/유럽)는 비교·참고 대상 | 거래 가능 |
| 병목 사업 비중 | 매출의 30% 초과가 병목 고리에서 발생 | 순수도 |
| 시가총액 | 10조원 미만 우선 (해외는 100억 달러 미만) | 대형주는 이미 충분히 가격 반영 |
| 유동성 | 일평균 거래대금 10억원 초과 (해외는 100만 달러 초과) | 진입·청산 가능 |
| 거래 상태 | 관리종목·거래정지·투자경고/위험 지정 종목 제외 | 거래 리스크 |

### 4.2.1 밸류에이션 점검 (반드시 실행, 생략 불가)

**병목이 진짜 ≠ 투자 기회.** 모든 기업의 PSR, PER을 계산해 리포트에 표기해야 합니다. 한국 상장사는 `python3 tools/kstock_data.py valuation {종목코드}`와 `financials {종목코드}`로 수집하고, 두 출처 이상 교차 검증합니다(`skills/financial-data.md` 기준, 네이버금융·FnGuide 직접 접속은 금지 — WebSearch로 대체). 아래 조합 조건으로 밸류에이션 과열 여부를 판단합니다:

#### 밸류에이션 적신호 (하나라도 해당 → 신호 강도 상한 ★2, "⚠️ 밸류에이션 과열" 표기)

1. **시가총액 > TAM의 20%**: 시가총액이 도달 가능한 시장 규모의 20%를 넘었다면 성장 기대가 과도하게 반영된 것
2. **PSR > 30배 이고 매출 증가율 < 100%**: 밸류에이션은 높은데 성장이 받쳐주지 못함. 증가율 >100%인 기업은 PSR 기준 면제 가능하나 "⚠️ 고밸류, 고성장 지속 검증 필요" 표기
3. **시가총액 > 5년 낙관 매출 전망의 10배**: 가장 낙관적 가정이 모두 실현돼도 현재 가격이 여전히 높음
4. **유상증자·CB 발행 후 60일 안에 주가 2배**: 심리 주도 성격이 뚜렷함, 신호 강도 한 단계 하향

#### 밸류에이션 황신호 (추가 설명이 없으면 하향)

1. **적자 + PSR > 15배**: ★3까지 허용하되 흑자 전환 경로와 일정 설명 필수
2. **PSR이 흑자인 동종사의 5배 이상**: 프리미엄의 근거(점유율, 성장률 차이, 진입장벽 차이) 설명 필수
3. **PER > 80배**: PEG를 계산하고 성장률이 이를 뒷받침하는지 설명

#### 밸류에이션 녹신호 (가점)

- PSR < 10배이고 매출 성장 중 → 신호 강도 한 단계 상향 가능
- PER < 30배이고 해자 보유 → "밸류에이션 안전마진 있음" 표기

#### 밸류에이션 합리성 검증 (필수)

종목마다 답합니다: "현재 시가총액으로 매수하고, 가장 낙관적 시나리오가 모두 실현되어 10년 후 PER 25배로 청산하면 연환산 수익률은?" 연환산 수익률 <10% → "현재 가격은 안전마진 없음" 표기. 계산은 `tools/financial_rigor.py calc` 또는 `three-scenario`로 검산합니다.

**주의**: 밸류에이션 점검의 목적은 "PSR 100배 적자 기업" 추천 같은 명백한 오류를 막는 것이지, 고밸류 초기 기업을 전부 배제하는 것이 아닙니다. 핵심은 성장률, TAM, 경쟁 구도가 현재 밸류에이션을 뒷받침하는지이며, 일괄 기준이 아닌 구체적 분석이 필요합니다.

**한국 상장사 검증 신호** (월간 매출을 공시하는 대만과 달리 한국은 분기 실적이 기본이므로 아래 신호를 활용):
- **DART 단일판매·공급계약체결 공시**: 계약 상대방(비공개 시 "영업비밀"), 계약금액, 최근 매출 대비 비율, 계약 기간 — 병목 수요가 실제 수주로 이어지는지 가장 빠른 공시 신호
- **DART 신규시설투자 공시**: 증설 규모와 일정 — 병목 해소 속도 판단
- **관세청 수출입 통계(10일·월간, 품목별 HS코드)**: 해당 품목의 수출 물량·단가 추이로 "물량·가격 동반 상승" 검증
- **해외 경쟁사·고객사(대만주 등)**: 대만 상장사는 매월 10일 전 전월 매출을 공시하므로 `python3 tools/twstock_data.py`로 고객사·경쟁사 월매출을 확인해 업황 신호로 활용

1차 선별을 통과한 기업을 하나씩 평가합니다:

```
- 공급망 내 구체적 위치
- 시장점유율: 글로벌 X위, 점유율 XX%
- 고객 명단 (알려진 범위, 공시상 "영업비밀"이면 그대로 표기)

**생산능력과 증설**:
- 현재 생산능력 / 가동률 (사업보고서 "생산 및 설비" 항목)
- 증설 계획 / 일정 (신규시설투자 공시)
- 증설 소요 자금 vs 보유 현금

**재무 스냅샷** (단위: 억원):
- 시가총액 / 매출 / 영업이익 / 순이익 / 증가율
- 병목 사업 매출 비중
- 매출총이익률 추세 (병목이 심할수록 이익률은 올라가야 함)

**리스크 체크리스트**:
- [ ] 대체 기술 리스크: 우회될 수 있는가?
- [ ] 희석 리스크: 대규모 유상증자/CB·BW 발행, 미전환 CB 오버행, 리픽싱 조건이 있는가?
- [ ] 지정학 리스크: 민감 지역 소재/수출 통제 대상인가? 중국 매출·조달 의존도는?
- [ ] 경영진·지배구조 리스크: 과거 불량 이력, 대주주 지분 담보·매도, 보호예수 해제 예정이 있는가?
- [ ] 고객 집중 리스크: 단일 고객 의존이 과도한가? (상위 고객 매출 비중)
- [ ] 테마 과열 리스크: 실적 없이 "AI/원전/방산 관련주" 테마로만 급등했는가?
- [ ] 밸류에이션 과열: 현재 밸류에이션이 3년 성장을 이미 반영했는가?

**병목 지속성 판단**:
- 이 병목은 언제 해소될까?
- 해소된 뒤 이 회사에 무엇이 남는가?
- 일회성인가, 지속적인가?
```

## 5단계: 교차 검증 — 한 가지 이야기만 듣지 않기

### 5.1 정방향 검증

| 검증 항목 | 질문 | 검색 방식 |
|--------|------|---------|
| 고객 검증 | 주요 고객이 이미 계약/채택했는가? | DART 공급계약 공시, 고객사 실적·IR에서 언급 여부 |
| 매출 검증 | 병목이 이미 매출 증가로 나타났는가? | 최근 2~3개 분기 실적 |
| 가격 검증 | 제품 가격이 오르고 있는가? | 업계 단가 동향, 수출 단가(관세청), 증권사 리포트 |
| 생산능력 검증 | 생산능력이 정말 빠듯한가? | 리드타임 데이터, 고객사의 공급 부족 언급 |
| 자본 검증 | 증설 CAPEX가 있는가? | 신규시설투자 공시, CAPEX 가이던스 |

### 5.2 역방향 검증 (멍거식 부정)

| 역질문 | 의미 |
|---------|------|
| 똑똑한 사람들은 왜 이 주식을 사지 않는가? | 이미 알려진 약세 논거 찾기 |
| 이 병목은 우회될 수 있는가? 대체 경로는? | 기술 경로 리스크 |
| 중국/다른 업체가 빠르게 생산능력을 복제할 수 있는가? | 공급 충격 리스크 |
| 최종 수요가 50% 둔화되면 이 회사는 어떻게 되나? | 하방 민감도 |
| 경영진이 과거 고점에서 유상증자·CB로 희석시킨 적이 있는가? | 경영진 신뢰도 |
| 현재 밸류에이션은 어떤 성장 가정을 내포하는가? | 밸류에이션 합리성 |

### 5.3 신호 교차 검증

- 같은 병목의 여러 기업(국내·해외)이 모두 오르고 있는가? (산업 검증)
- 하류 고객이 실적 발표에서 공급 부족을 언급하는가? (고객 검증)
- 업계 협회/연구기관(반도체산업협회, 산업통상자원부, 시장조사기관 등)에 관련 데이터가 있는가? (제3자 검증)

## 6단계: 출력 — 병목 기회 보드

### 6.1 병목 기회 순위표

| 순위 | 기업 | 종목코드 | 시가총액 | 연매출 | PSR | PER | 병목 고리 | 병목 등급 | 시장점유율 | 매출 증가율 | 신호 강도 | 밸류에이션 판단 |
|------|------|------|------|--------|-----|-----|---------|---------|---------|---------|---------|---------|
| 1 | | | | | x | x | | S/A | | | ★1~5 | 적정/다소 높음/과열 |

**필수 항목**: 시가총액, 연매출, PSR, PER은 필수이며 "확인 필요"로 건너뛸 수 없습니다. 재무 데이터를 확보하지 못하면 신호 강도는 ★2를 넘을 수 없습니다. 통화 단위(원/달러)를 반드시 표기합니다.

신호 강도 등급 (밸류에이션 점검 결과가 등급에 직접 반영):
- ★5: 다중 교차 검증, 고객 채택 완료, 매출 반영 확인, 밸류에이션 녹신호(PSR 적정 + 흑자 또는 흑자 근접)
- ★4: 대부분 검증 통과, 밸류에이션 녹신호 또는 황신호(설명 첨부)
- ★3: 논리는 성립하나 일부 검증 대기, 밸류에이션 황신호 수용 가능(고성장 초기 기업 등)
- ★2: 초기 신호, 또는 병목 논리는 성립하나 밸류에이션 적신호(시가총액 >TAM 20%, PSR >30배에 성장 부족, 시가총액이 5년 전망을 크게 초과 등)
- ★1: 순수 테마, 미검증

## 정기 스캔 모드 (예약 작업용)

장중에는 매시간, 장외에는 필요 시 실행하며 "새로운 것이 있을 때만 리포트" 방식을 씁니다:

### 스캔 절차 (회차별)

1. **뉴스 스캔**: 최근 1~2시간의 공급망 관련 뉴스 검색
   - 키워드: supply chain bottleneck, shortage, capacity constraint, allocation, lead time, sole source, 병목, 공급 부족, 쇼티지, 증설, 수주, 단가 인상, 리드타임
   - 범위: 한국어 + 영어 출처 (필요 시 일본·대만 출처)
2. **공시 스캔**: 추적 기업의 DART 공시 확인 — 단일판매·공급계약체결, 신규시설투자, 유상증자·CB 발행, 잠정실적
3. **시장 신호**: 추적 기업의 주가 변화 확인 (특히 ±5% 초과 급변은 `/news-pulse`로 원인 확인 가능)
4. **밸류에이션 기회**: watchlist 기업이 시장 하락 등으로 매수 검토 구간에 들어왔는지 확인
5. **리포트 여부 판단**:
   - 새 병목 신호, 명확한 종목 기회, 중대한 상태 변화가 있음 → **리포트 작성**
   - 새 발견 없음 → **리포트 생략**, 로그에 "이번 회차 신규 신호 없음"만 기록

### 리포트 출력 규칙

**하루 한 폴더**: `reports/bottleneck-map/YYYY-MM-DD/`

**파일명 규칙** (파일명만 보고 종목 유무를 알 수 있게):

| 상황 | 파일명 형식 | 예시 |
|------|-----------|------|
| 명확한 종목 발견 | `HH-MM-종목코드1-종목코드2.md` | `09-00-123456-654321.md` |
| 병목 신호는 있으나 명확한 종목 없음 | `HH-MM-신호스캔.md` | `14-00-신호스캔.md` |
| 새 발견 없음 | 파일 생성 안 함 | — |

**파일명의 종목코드 = 밸류에이션 점검을 통과해 심층 리서치 가치가 있는 기업.** 신호 스캔 단계에만 등장하고 밸류에이션 기준에 미달한 기업은 파일명에 넣지 않습니다. 한국 상장사는 6자리 종목코드, 해외 상장사는 현지 티커를 씁니다.

## AI 리서치 편향 자각

| 편향 | 증상 | 대응 |
|------|-----|------|
| 대장주 선호 | 검색 결과가 대형주로 채워짐 | 의도적으로 소형 공급사 검색, "small cap"·"소부장"·"중소형주" 키워드 추가 |
| 영어 선호 | 한국·일본·대만 기업 누락 | 한국어 검색을 반드시 병행하고, 일본·대만 공급사도 검색 |
| 서사 선호 | "AI 관련주" 같은 테마 라벨에 끌림 | 실제 공급망 위치만 보고 시장 라벨은 보지 않음 |
| 확증 편향 | 병목을 찾은 뒤 긍정적 증거만 찾음 | 역방향 검증(5단계) 강제 실행 |
| 시의성 편향 | 오래된 정보에 의존 | 최근 30일 데이터를 우선 검색 |

## 핵심 원칙 (최우선)

1. **AI에게 종목 추천을 시키지 말고 공급망을 분해하게 하라** — 질문이 답보다 중요
2. **물리 우선** — 실제 물리적 제품/소재/장비가 필요한 고리에만 집중
3. **2차·3차 병목** — 이미 충분히 가격에 반영된 대장주를 쫓지 않음
4. **교차 검증** — 모든 결론에 최소 2개 독립 출처
5. **불확실성을 정직하게** — 데이터를 못 찾으면 "데이터 부족"이라 쓰고 추측으로 채우지 않음
6. **병목에는 유효기간이 있다** — 모든 병목은 언젠가 해소되며, 핵심은 시간 창을 판단하는 것
7. **소형주 ≠ 좋은 기회** — 소형주도 나쁜 회사일 수 있으니 재무 품질 관문을 반드시 통과해야 함
8. **병목이 진짜 ≠ 투자 기회** — 가장 빡빡한 병목 위에 앉아 있어도 PSR >30배이거나 적자라면 지금 가격은 매수 시점이 아님. **밸류에이션은 하드 게이트이며, 병목 순수도·신호 강도·서사의 매력으로 덮을 수 없다.** 오른 병목주를 놓칠지언정 PSR 100배 적자 기업을 사지 않는다
9. **CLAUDE.md 객관성 원칙 준수** — 강세를 미리 정하지 않고, 데이터 먼저 결론은 나중
