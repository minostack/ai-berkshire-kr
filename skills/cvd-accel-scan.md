# CVD 가속 스캐너 (설계 accel-1.0) — 1분봉

일별 CVD 흐름의 **변화율(가속)** 로 종목을 고릅니다. 기존 `/cvd-obv-scan`(V1.5)이
`종가>MA20`·`OBV>MA20`·`매수우위일≥50%` 같은 **수준(level)** 조건으로 "이미 오른
종목"을 뽑던 문제를 겨냥한 별도 설계입니다.

**지원 입력 형식**:

```
/cvd-accel-scan                        # 코스피200+코스닥150 통합, 1분봉, 상위 15
/cvd-accel-scan kospi200               # 코스피200만
/cvd-accel-scan kosdaq150              # 코스닥150만
/cvd-accel-scan top 30                 # 출력 종목 수 변경
/cvd-accel-scan detail 005930          # 단일 종목 — 일별 흐름 10일 막대 출력
/cvd-accel-scan check                  # 앞 3종목만 돌려 연결 확인
```

## 무엇을 계산하는가

```
일별 정규화 흐름  f_d = Σ(거래량 × direction) / Σ거래량      (-1 ~ 1, 정규장만)
최근  = mean(f, D-2 … D)      3거래일
이전  = mean(f, D-9 … D-3)    7거래일
가속 A = 최근 - 이전
```

`f_d`는 V1.5 `calc_cvd()`에 **하루치 봉만 넘겨서** 얻습니다(`normalized_delta`가
정의상 그날의 f_d). 계산식을 다시 쓰지 않는 이유는 하나입니다 — 두 도구가 다른
숫자를 내면 어느 쪽이 맞는지 알 수 없습니다.

## 게이트 (5개 — 백테스트 정의 그대로)

1. 최근 10거래일 f가 **연속으로** 존재(완료된 정규장 기준)
2. **가속 A > 0**
3. **최근 3일 흐름 > 0** (음수에서 덜 음수로 가는 것은 가속이지만 매수 우위가 아님)
4. 유동성(20일 평균 거래대금) 데이터 존재
5. **과열 제외: 종가가 MA20 대비 +10% 이내**

**의도적으로 넣지 않은 조건**: `종가 > MA20`, `OBV > OBV MA20`,
`매수우위일 ≥ 50%`, 30분 모멘텀. 전부 "이미 올랐다"를 확인합니다. 조건 5는
MA20을 **반대 방향으로** 씁니다 — 상회를 요구하지 않고 과열만 막습니다.
OBV·MA20 상회 여부는 화면에 **참고 표시만** 하고 판정에 쓰지 않습니다.

> `tests/unit/test_cvd_accel_scanner.py::test_MA20_아래여도_OBV가_아래여도_후보가_된다`
> 가 이 제외를 회귀로 고정합니다. 되돌리면 테스트가 깨집니다 — 설계 목적이
> 사라지기 때문입니다.

**백테스트와 다른 한 가지**: 실거래 스캔은 V1.5의 **분봉 품질 판정
(`data_status == SUCCESS`)** 을 추가로 요구합니다(미달 → `DATA_INSUFFICIENT`).
백테스트는 이미 수집·검증된 저장 봉을 읽었으므로 이 검사가 없었습니다. 선정
기준을 조인 것이 아니라 **수집 결함을 신호로 착각하지 않기 위한 가드**입니다.

## 실행 시점

- 흐름은 **완료된 정규장**만 씁니다. 장중에 돌리면 신호 기준일이 **직전
  거래일**이 되고, 도구가 그 사실을 경고로 출력합니다
- 확정 종가 기준 진입은 **시간외 종가매매(15:40~16:00)** 로 집행 가능합니다
  (동시호가 경로만 불가) → **15:35 이후 실행**이 설계에 맞습니다
- 1분봉 12거래일 × 350종목이면 분봉 호출만 6~15분 걸립니다(초당 5회 제한)

## 출력 해석

```
  순위 종목            점수     가속A      최근      이전   MA20이격   거래대금  OBV   판정
     1 066570 LG전자   93.0  +0.0868  +0.0837  -0.0031     +3.3%   1,445억   ▲  🟩후보
```

| 열 | 좋은 값 | 의미 |
|---|---|---|
| 가속A | **> 0, 클수록** | 매수 흐름이 빨라지는 정도 |
| 최근 | **> 0** | 최근 3거래일 매수 우위 |
| 이전 | (참고) | 음수였다가 최근에 양수로 바뀌면 가속이 크다 |
| MA20이격 | +10% 이내 | 초과 시 과열로 탈락 |
| OBV ▲/▽ | **판정에 쓰지 않음** | ▽가 많은 것이 정상 — 아직 안 오른 종목을 고르는 설계 |

판정: `🟩후보`(5조건 충족) / `🟨관찰`(사유 표시) / `⬜부족`(흐름 미확보·품질 미달)

**봉 완성도 80% 미만인 날**이 창에 섞이면 경고로 표시하되 게이트에는 반영하지
않습니다 — 백테스트 정의를 그대로 두기 위한 선택입니다.

## 주의사항

1. **수익은 검증되지 않았습니다.** 선행성만 확립됐습니다
2. **CVD는 분봉 캔들 추정치**입니다(체결 데이터 아님) — 절대값보다 방향
3. 봉 기준 `bars-1.0`(`docs/BAR_STANDARD.md`): 일봉은 로컬 **정규장** 일봉(MA20
   이격·유동성), 분봉은 키움 1분봉입니다. 일봉 완료는 15:35(`--daily-scope regular`).
   로컬 일봉은 16:10 잠정 `data-load provisional` + 익일 08:30 확정 `data-load daily`로 갱신합니다. 2026-10-03
   이전 결과(일봉 = 애프터마켓 최종가)와는 MA20 이격 값이 다를 수 있습니다
4. `--recent/--prior/--overheat`를 바꾸면 **검증된 설계가 아닙니다**. 민감도
   확인용으로만 쓰고, 결과를 주 설정과 같은 표에 섞지 마세요
5. 왕복 비용 0.409%입니다. 2거래일 회전이면 연 24~50%가 비용입니다
6. **이 스캔 결과는 투자 권유가 아닙니다**
