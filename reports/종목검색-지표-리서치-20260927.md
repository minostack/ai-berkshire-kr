## 1. 우리 리스트에 정보가 있는가 — 직접 측정

### 1.1 왜 새로 측정했는가

지금까지 측정한 것은 **"2거래일 보유 + 손절/트레일링 규칙"의 성적**이었다.
"규칙이 나빴다"와 "리스트에 아무 정보가 없다"는 다른 주장이고, 후자는 직접
측정하지 않았다. 그래서 규칙을 전부 걷어내고 **종가→종가 단순 보유**만 남겼다.

**판정 기준은 실행 전에 고정했다.** 어느 지평에서든 유니버스 대비 초과수익의
95% 신뢰구간이 0을 제외하면 그 지평에서 리스트가 정보를 갖는다고 본다. 전
지평에서 0을 포함하면 유니버스와 구별되지 않는다. 신뢰구간은 같은 날 종목들이
독립이 아니므로 **거래일로 묶은 블록 부트스트랩**(4,000회)으로 만들었다.

- 구간: 2025-09-12 ~ 2026-09-22, **250거래일**, 1분봉 replay(`-p1b10-`)
- 유니버스: 코스피200 + 코스닥150, 스캔 행 87,232건
- 후보 수: 기존 게이트 13,060건 / 가속 28,348건
- 비용·세금 미반영(순수 지표 정보량만 본다)

### 1.4 판정

**기존 게이트 리스트는 "매수 신호"로서 의미가 확인되지 않는다.**

- 10개 지평 중 **9개에서 점수 부호가 음수**다.
- 유일하게 신뢰구간이 0을 제외한 칸(후보 전체 D+2)이 **불리한 방향**이다.
- 유니버스를 이긴 날이 **38.9~49.2%** — 모두 50% 미만이다.
- 즉 "종목을 잘못 골랐다"기보다 **골라낸 것이 유니버스와 다르지 않거나 약간
  나쁘다**. 같은 1분봉 replay에서 선정 종목의 **97.8%가 신호 전 10거래일에 이미
  평균 +20.15% 올라** 있었던 사실과 방향이 일치한다 — 단기 반전 구간을 사고
  있었을 가능성(**추정**).

**가속 리스트는 부호가 뒤집혔지만 아직 유의하지 않다.**

- 다섯 지평 중 넷이 양수이고, D+5에서 +0.525% / 이긴 날 53.5%가 가장 크다.
- 그러나 신뢰구간이 모두 0을 포함한다. **250거래일 1년 표본으로는 판정할 수
  없다** — 앞선 일봉 대리 장기검증(15.7년)은 오히려 음수였다.

### 1.5 이 측정의 한계

1. **표본 1년(250거래일)** — 검정력이 낮다. 초과수익 ±1%p 수준은 이 표본에서
   원리상 구별되지 않는다.
2. **유니버스가 코스피200+코스닥150** — 대형주 편중. 소형주에서 같은 결론일지는
   측정하지 않았다.
3. **비용 미반영** — 비용을 넣으면 모든 회전 전략이 더 나빠진다(§4).
4. **단순 종가 보유** — 실제로는 체결·유동성 제약이 있다.
5. 가속 리스트는 **replay 유니버스 안에서 사후 재선정**한 것이다. 기존 게이트
   리스트와 같은 조건(같은 날·같은 후보 모집단)이지만, 실거래 스캔과 완전히
   동일한 절차는 아니다.

### 2.2 차트 플랫폼 기본 탑재 지표

TradingView 등의 기본 지표는 **이동평균(SMA/EMA), RSI, MACD, 볼린저밴드,
거래량 프로파일·VWAP, ATR** 계열로 수렴한다([Liberated Stock Trader](https://www.liberatedstocktrader.com/best-tradingview-indicators/), [Supertrade](https://supertrade.com/blog/best-tradingview-indicators/), `[요약]`).

> ⚠ **주의 — 사용률 수치는 쓰지 않았다.** "리테일 73%가 5개 이상 지표를
> 쓴다", "기관 78%가 기술적 분석을 쓴다" 같은 숫자가 여러 블로그에 돌지만,
> 원 조사 보고서를 찾을 수 없었다. 출처 불명 수치는 이 문서에 싣지 않는다.
> **"많이 쓰인다"의 근거로는 증권사 화면에 기본 탑재돼 있다는 사실만 쓴다.**

## 3. 지표군별 근거 상태

### 3.1 근거가 비교적 강한 것

| 지표군 | 무엇을 재는가 | 근거 | 한국시장 |
|---|---|---|---|
| **실적 서프라이즈 후 표류(PEAD)** | 실적 발표 후 주가가 서프라이즈 방향으로 수주~수개월 계속 표류 | Ball–Brown(1968) 이후 "가장 강건하고 가장 풀리지 않은 이상현상" 중 하나로 반복 확인 `[요약]` | 한국 상장주 2001~2014 표본에서 PEAD 확인, **52주 신고가 근접도가 클수록 표류가 커진다** ([Pacific-Basin Finance Journal 44, 2017](https://www.sciencedirect.com/science/article/abs/pii/S0927538X1730094X)) `[요약]` |
| **거래량 급증(RVOL)** | 하루~한 주 비정상 거래량 | 고거래량 종목이 이후 **약 1개월간** 초과 상승 — "high-volume return premium" (Gervais·Kaniel·Mingelgrin, [Journal of Finance 56, 2001](https://onlinelibrary.wiley.com/doi/abs/10.1111/0022-1082.00349)). 규모조정 월 초과수익 0.53%(시총가중)·0.68%(동일가중) `[요약 — 원문 PDF 대조 실패]` | 별도 확인 못 함(**데이터 부족**) |
| **52주 신고가 근접** | 현재가가 52주 최고가에 얼마나 가까운가 | George·Hwang(2004): 52주 고가를 기준점(앵커)으로 삼아 뉴스에 과소반응 → 모멘텀 수익의 상당 부분을 설명 `[요약]` | 위 PEAD 연구와 결합 확인. **외국인 지분이 높은 종목에서는 앵커링 효과가 사라진다** `[요약]` |
| **유동성/비유동성** | Amihud ILLIQ = 일간 \|수익률\| ÷ 거래대금 | Amihud(2002): 비유동성이 높을수록 기대수익이 높다 `[요약]` | — |

|---|---|

| | Bajgrowicz·Scaillet([Journal of Financial Economics, 2012](https://www.sciencedirect.com/science/article/abs/pii/S0304405X1200116X)): DJIA 1897~2011, FDR 기법으로도 **미래에 좋을 규칙을 사전에 고를 수 없었고, 표본 내 성과조차 낮은 거래비용만 넣으면 전부 상쇄됐다** `[요약]` |

| **지표 일반** | McLean·Pontiff([Journal of Finance 71, 2016](https://onlinelibrary.wiley.com/doi/abs/10.1111/jofi.12365)): 학술 검증된 예측변수 97개의 수익이 **표본외 -26%, 공표 후 -58%** `[요약, 복수 출처 일치]` |
| | Hou·Xue·Zhang([Review of Financial Studies 33, 2020](https://academic.oup.com/rfs/article-abstract/33/5/2019/5236964)): 이상현상 452개 중 **65%가 t≥1.96조차 넘지 못했다**(다중검정 기준 2.78에서는 82.1% 실패) `[요약]` |
| | Harvey·Liu·Zhu(2016): 발표된 요인 316개 — 새 요인은 **t>3.0**을 넘어야 한다 `[요약]` |

|---|---|
| **가격 모멘텀(12-1)** | 미국에서는 표준 요인이지만 **한국에서는 약하거나 반전이 우세하다**는 보고가 반복된다 `[요약]`. Jegadeesh·Titman의 30년 회고(2023)가 2000~2020 아시아(한국 포함)에서 모멘텀 지지 증거를 찾지 못했다는 인용이 있다 `[요약 — 원문 미확인]` |
| **수급 추종(외국인·기관 순매수)** | 기관·외국인은 모멘텀 거래자, 개인은 역추세 거래자이고 성과는 기관이 가장 좋았다는 국내 연구 요약이 있다(한양대, 財務管理硏究 2012) `[요약 — 원문 PDF 접근 실패, 미확인]`. **우리 데이터로 재현 검증하지 않았다** |
| **저변동성·BAB** | Frazzini·Pedersen의 BAB는 글로벌로 확립됐지만, **한국 표본에서는 베타 추정 편향 때문에 가설이 지지되지 않는다**는 연구가 있다 `[요약]` |

## 4. 지표보다 큰 제약 — 비용과 회전

우리 비용모델(`configs`, `krx_v1`) 실측:

| 항목 | 값 |
|---|---:|
| 매수 수수료 | 0.015% |
| 매도 수수료 | 0.015% |
| 거래세(매도) | 0.18% |
| 슬리피지(편도) | 0.10% |
| **왕복 합계** | **0.409%** |

**같은 값을 우리 시뮬레이션 회전율에 곱해 보면** — 250거래일에 292~617회
매매했고(5슬롯, 자리당 자본 20%), 자리당으로는 연 58~123회전이다.

```
연 비용 = 0.409%(왕복) × 매매횟수 × 20%(자리 비중)
        = 0.409% × 292 × 0.2 = 23.9%      (가속 설계, 292회)
        = 0.409% × 617 × 0.2 = 50.5%      (기존 게이트 bdays=10, 617회)
```

**자본의 연 24~50%가 비용으로 나간다.** §1에서 본 초과수익 후보값(최대
+0.525%p)은 **왕복 비용 0.409%를 겨우 넘는 수준**이고, 신뢰구간이 0을
포함하므로 비용을 덮을 만큼 크다고 말할 수 없다.

**이것이 이번 리서치의 실질적 결론이다(의견)**: 지표를 바꿔서 얻어야 하는
초과수익의 크기는 보유기간이 짧을수록 비현실적으로 커진다. 근거가 강한
지표군(PEAD, 거래량 급증, 52주 신고가)이 공통적으로 **수주~수개월** 지평인
것과, 우리가 2거래일에서 우위를 못 찾은 것은 같은 이야기의 양면일 수 있다.

| 후보 | 왜 | 보유기간 | 우리가 이미 가진 것 | 없는 것 |

A는 서프라이즈 정의가 결과를 좌우하므로 정의를 먼저 고정해야 한다.
