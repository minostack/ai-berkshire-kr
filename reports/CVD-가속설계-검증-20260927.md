# CVD 가속 설계 — 선행성은 얻었고, 수익은 증명되지 않았습니다

작성일 2026-09-27 · 검증 기간 2025-09-12 ~ 2026-09-22 (250거래일)
· 분봉 **1분** · 코스피200 + 코스닥150

---

## 1. 결론

두 결과를 **분리해서** 읽어야 합니다. 하나는 재현되고 하나는 재현되지
않습니다.

### ① 목표는 달성했습니다 — 신호가 움직임 **앞**으로 옮겨졌습니다

| 측정 | 기존 게이트 | MA20 제거(V3) | **CVD 가속** |
|---|---:|---:|---:|
| 신호 전 상승폭 D−10→D | +20.15% | +18.86% | **+0.25%** |
| 신호 전 상승 종목 비율 | 97.8% | 95.1% | **55.2%** |
| 하루 먼저의 우위 | +1.96% | +1.83% | **+1.48%** |

**선정 종목이 신호 전에 평균 0.25%밖에 오르지 않았습니다**(기존 20.15%).
올라 있던 종목 비율도 97.8% → 55.2%로 내려왔습니다. 동전 던지기에
가깝다는 뜻이고, 이것이 "이미 오른 종목을 확인하는 신호"에서 벗어났다는
증거입니다.

**그리고 이 성질은 설계 인자를 바꿔도 유지됩니다**(§6) — 다섯 설정 전부
−2.42% ~ +7.88%로, 기존 +20.15%와 자리수가 다릅니다.

### ② 수익은 증명되지 않았습니다

| | 값 |
|---|---:|
| 최종 평가액 | **14,510,017원** |
| 수익률 | **+45.1%** |
| 거래 / 승률 | 292 / 46.6% |
| MDD | -22.8% |

숫자는 크지만 **세 가지가 이 숫자를 믿지 못하게 합니다.**

| 검정 | 결과 |
|---|---|
| 거래당 순수익 95% 신뢰구간 | +0.709% **[−0.207%, +1.683%]** — **0을 포함** |

**3+7 대신 5+5로 나눴다면 −2.1%였습니다.** 분할 비율은 이론적 근거가 없는
선택이고, 그 선택 하나가 47%p를 만듭니다. 거래당 우위도 0과 구분되지
않습니다.

**정리: 설계 의도(선행성)는 달성·재현됐고, 수익성은 이 검증으로 주장할 수**
**없습니다.**

## 2. 설계 — 실행 전에 고정했습니다

결과를 보고 조건을 고치면 과최적화가 되므로, 아래 정의를 먼저 확정하고
한 번 돌렸습니다.

### 왜 가속인가

기존 게이트는 `종가 > MA20`, `OBV > OBV MA20`, `매수우위일 ≥ 50%`를
요구합니다. 전부 **수준(level)** 조건이고 "이미 올랐다"를 확인합니다.
MA20을 빼도 95.1%가 사전 상승 종목이었으므로, 조건 하나의 문제가
아니었습니다.

그래서 **수준이 아니라 변화율**로 바꿉니다. 매수 흐름이 *빨라지고 있는가*는
가격이 아직 움직이지 않았을 때도 켜질 수 있습니다.

### 입력 — 일별 CVD 흐름을 새로 계산했습니다

저장된 `cvd_normalized_delta`는 10일 **전체 합**, `cvd_normalized_momentum`은 마지막 **30분**입니다. 사이의 일별 시계열이
없어 가속을 만들 수 없으므로 1분봉에서 다시 계산했습니다.

```
direction = clamp(0.6·CLV + 0.4·Body, −1, 1)      # V1.5와 동일
Delta_i   = 거래량 × direction
일별 흐름  f_d = Σ Delta_i / Σ 거래량              # −1 ~ 1, 정규장 1분봉
```

실측 101,878 (종목,일) · f 평균 +0.0054 / 중앙 +0.0027 / 표준편차 0.1088 ·
f>0 비율 51.0%.

### 가속 정의

```
최근 = mean(f, D−2 … D)      3거래일
이전 = mean(f, D−9 … D−3)    7거래일
가속 A = 최근 − 이전
```

10거래일 창을 3+7로 나눕니다(기존 `bdays=10`과 같은 창).

### 게이트 (5개)

| # | 조건 | 성격 |
|---|---|---|
| 1 | 최근 10거래일 f가 모두 존재 | 데이터 |
| 2 | **가속 A > 0** | **핵심** |
| 3 | 최근 3일 흐름 > 0 | 음수→덜음수 배제 |
| 4 | 유동성 데이터 존재 | 데이터 |
| 5 | **종가가 MA20 대비 +10% 이내** | **과열 배제** |

**의도적으로 넣지 않은 것**: 종가 > MA20, OBV > OBV MA20,
매수우위일 ≥ 50%, 30분 모멘텀. 전부 "이미 올랐다"를 확인합니다.

조건 5는 MA20을 **반대 방향으로** 씁니다 — 상회를 요구하지 않고 과열만
막습니다. 선행성을 얻기 위한 조건입니다.

## 3. 결과를 의심했습니다 — 선행 참조 감사

+45%가 나오면 먼저 틀렸을 경로를 찾아야 합니다. 가장 의심스러운 곳은
동점 정렬키인 `avg_traded_value_20d`입니다. 이게 미래를 포함하면 순위가
미래를 봅니다.

일봉에서 직접 20일 평균을 다시 계산해 대조했습니다.

```
표본 3,000건 중 과거 20일 평균과 일치 2,999 (100.0%)
                미래 20일 평균과 일치     0
```

**선행 참조 없음** — D를 포함한 과거 20일입니다.

다른 입력도 점검했습니다. 일별 흐름 `f_d`는 정규장(15:30 종료) 1분봉으로
계산하고 판정은 15:35이므로 당일 포함이 선행 참조가 아닙니다. 백분위는
그날 유니버스 안에서만 계산하고, 청산 스캔은 D+1부터 시작합니다.

## 5. 거래당 우위는 0과 구분되지 않습니다

날짜를 관측 단위로 둔 블록 부트스트랩(5,000회, 블록 2거래일)입니다.
같은 날 5종목은 서로 독립이 아니므로 거래를 하나씩 재표집하면 구간이
실제보다 좁아집니다.

| | 값 |
|---|---|
| 거래 / 날짜 | 292건 / 161일 |
| 거래당 순수익 평균 | **+0.709%** |
| 95% 신뢰구간 | **[−0.207%, +1.683%]** |
| 0 포함 | **예** |

총 수익률 +45.1%는 292회 회전의 복리 결과이지만, **한 거래의 우위는
통계적으로 0과 구분되지 않습니다.** 292건 · 161일은 이 크기의 효과를
확정하기에 부족한 표본입니다.

## 6. 민감도 — 수익률은 설계 선택에 좌우됩니다

주 설정(3+7 · 과열≤10%)을 먼저 고정한 뒤, 다른 선택이었다면 어땠는지
확인했습니다. **주 설정을 바꾸지 않았습니다** — 좌우되는지만 봅니다.

| 설정 | 통과 | 수익률 | 거래 | 승률 | 신호 전 상승폭 | 상승 비율 |
|---|---:|---:|---:|---:|---:|---:|
| **3+7 · 과열≤10% (주)** | 28,345 | **+45.1%** | 292 | 46.6% | +0.25% | 55% |
| 5+5 · 과열≤10% | 25,981 | -2.1% | 313 | 42.5% | +0.85% | 60% |
| 2+8 · 과열≤10% | 29,774 | +15.1% | 284 | 44.4% | -0.02% | 55% |
| 3+7 · 과열≤5% | 23,686 | +64.7% | 279 | 47.7% | -2.42% | 42% |
| 3+7 · 과열조건 없음 | 33,911 | +46.1% | 363 | 45.7% | +7.88% | 68% |

**읽는 법이 중요합니다.**

- **수익률은 −2.1% ~ +64.7%로 부호까지 갈립니다**(폭 66.8%p). 3+7이냐
  5+5냐는 이론적 근거가 없는 선택이고, 그 하나가 47%p를 만듭니다.
  **이 수익률을 설계의 성과로 주장할 수 없습니다.**
- **선행성은 다섯 설정 전부 재현됩니다.** 신호 전 상승폭이 −2.42% ~
  +7.88%이고, 기존 +20.15%와 자리수가 다릅니다. 상승 비율도 42~68%로
  기존 97.8%와 다릅니다.

즉 **가속으로 바꾸면 신호가 앞으로 온다는 것은 견고하고, 그것이 돈이
된다는 것은 견고하지 않습니다.**

설계 중 처음으로 대조군을 명확히 넘었습니다.

다만 §5의 신뢰구간이 0을 포함하므로, 이 대조군 우위와 거래당 검정이

신뢰구간은 **한 거래의 평균**을 봅니다 — 20개 표본에서 20/20은 단측
p≈0.05 수준이라 강한 증거가 아닙니다(의견).

## 10. 한계

1. **수익률은 설계 인자에 좌우됩니다**(§6, 폭 66.8%p). 이 검증으로
   수익성을 주장할 수 없습니다.
2. **거래당 우위가 0과 구분되지 않습니다**(§5).
3. **단일 기간입니다.** 앞/뒤 절반이 같은 방향인 것은 확인했지만
   (§4) 진짜 표본 외 기간이 아닙니다. 2025-09 이전 분봉이 없어
   표본 외 검증이 현재 불가능합니다.
4. **과열 상한 +10%는 임의값입니다.** ≤5%면 +64.7%, 없으면 +46.1%로
   바뀝니다. 이 값을 데이터로 고르면 그 순간 과최적화입니다.
5. **CVD는 추정치**입니다 — 체결 데이터가 아니라 1분봉 캔들 모양에서
   매수·매도를 나눈 값입니다(`0.6·CLV + 0.4·Body`, 검증 전 가중치).
6. **미체결 미반영.** 시간외 종가매매 전량 체결을 가정했습니다.
7. **봉 안 순서 가정은 "고가→저가"(보수적) 하나만 썼습니다.**
8. **합병 상장폐지 2종목**의 분봉은 받을 수 없습니다(생존편향의 반대 방향).
